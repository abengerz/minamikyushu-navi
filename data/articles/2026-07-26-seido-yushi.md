制度融資は、自治体・信用保証協会・金融機関の三者が関わります。この構造が分かっていないと、どこに相談すればよいか分かりません。

## 三者の役割

| 主体 | 役割 |
|---|---|
| **自治体（県・市町村）** | 制度を設計する。金融機関への預託、利子補給、保証料補助を行う |
| **信用保証協会** | 保証を行う。事業者が返済できない場合、金融機関に代位弁済する |
| **金融機関** | 実際に融資する。窓口になる |

自治体が制度を作り、保証協会が保証し、金融機関が貸す。この3つが揃って成立します。

:::point
**申込みの窓口は金融機関**です。自治体に行っても融資は受けられません。ただし、市町村の推薦や認定が必要な制度もあるので、事前に確認してください。
:::

## 信用保証協会の役割

信用保証協会は、各都道府県にあります。宮崎県信用保証協会、鹿児島県信用保証協会です。

事業者が返済できなくなった場合、保証協会が金融機関に**代位弁済**します。金融機関から見ると貸倒れのリスクが下がるため、実績の乏しい事業者にも融資しやすくなります。

### 代位弁済されると債務は消えません

よくある誤解です。

代位弁済が行われると、債権者が金融機関から保証協会に変わります。事業者は保証協会に返済する義務を負います。**借金がなくなるわけではありません。**

また、代位弁済の記録は残るため、その後の借入は極めて困難になります。

## 信用保証料

保証を受けるために保証料を払います。

- 借入金額と保証期間に応じて算出されます
- 料率は事業者の財務内容に応じて複数の区分があります
- 一括前払いが基本（分割払いが可能な場合もあります）

制度融資では、自治体が保証料の一部または全部を補助することがあります。これが制度融資を使う利点の1つです。

## 保証付き融資とプロパー融資

| | 保証付き融資 | プロパー融資 |
|---|---|---|
| 保証 | 信用保証協会が保証 | なし（金融機関が全リスクを負う） |
| 保証料 | 必要 | 不要 |
| 審査 | 保証協会と金融機関の両方 | 金融機関のみ |
| 借りやすさ | 比較的借りやすい | 実績と財務内容が必要 |
| 限度額 | 保証限度額がある | 金融機関の判断 |

創業時や実績の浅い時期は保証付きから始め、取引実績を積んでプロパーに進む、というのが一般的な流れです。

金融機関から見ると、プロパー融資を出すかどうかは信用の証です。[決算書の見られ方](/yushi/ginko-kessansho/)を意識した決算を続けることが、プロパーへの近道になります。

## 制度融資の種類

自治体によって名称と内容は異なりますが、おおむね次の類型があります。

| 類型 | 用途 |
|---|---|
| 創業支援資金 | 開業時の設備・運転資金 |
| 経営安定資金 | 業況悪化時の運転資金 |
| 設備投資資金 | 機械・建物の取得 |
| 小規模企業資金 | 小規模事業者向けの少額融資 |
| 事業承継資金 | 承継に伴う株式取得等 |
| 災害復旧資金 | 被災時の復旧 |

宮崎県・鹿児島県それぞれに制度があり、さらに市町村独自の制度がある場合もあります。詳しくは[県別のページ](/miyazaki/)から各自治体のサイトを確認してください。

## セーフティネット保証

業況が悪化している業種や、取引先の倒産で影響を受けた事業者向けの保証制度です。

利用するには、**市町村長の認定**が必要です。

1. 市町村の商工担当課に認定申請をする
2. 認定書の交付を受ける
3. 認定書を持って金融機関に申し込む
4. 保証協会の審査
5. 融資実行

認定の要件は号数によって異なります。対象業種が指定されているもの（5号）、取引先の倒産によるもの（2号）、災害によるもの（4号）などがあります。

:::warn
認定には有効期限があります。取得してから金融機関の審査に時間がかかると、期限切れになることがあります。並行して進めてください。
:::

## 申し込みの準備

金融機関に持っていく資料です。

1. 直近3期分の決算書（個人は確定申告書）
2. 直近の試算表
3. 資金繰り表
4. 借入金の一覧（金融機関別・残高・返済額・担保の有無）
5. 設備資金の場合は見積書
6. 納税証明書
7. 商業登記簿謄本

3番と4番を自分から出せる会社は、それだけで評価が変わります。[資金繰り表の作り方](/yushi/shikinguri-kihon/)を参照してください。

## 経営者保証

近年、経営者保証を求めない融資の取組が進められています。

「経営者保証に関するガイドライン」では、次の要件を満たす場合に、保証を求めない、または解除を検討することとされています。

1. 法人と経営者個人の資産・経理が明確に分離されている
2. 法人のみの資産・収益力で返済が可能である
3. 金融機関に対し、適時適切に財務情報が開示されている

1番が重要です。[役員貸付金](/yushi/ginko-kessansho/)があると、法人と個人が分離されていないと見られます。社長の個人的な支出を会社で払っている、会社の資金を個人が使っている、という状態を解消してください。

## どこに相談するか

| 状況 | 相談先 |
|---|---|
| これから創業する | [日本政策金融公庫](/yushi/kouko-yushi/)、商工会議所・商工会 |
| 既存の取引銀行がある | まずその銀行 |
| 取引銀行がない | 地元の信用金庫・地方銀行 |
| 業況が悪化している | 取引銀行＋市町村（セーフティネット認定） |
| 制度の内容を知りたい | 県・市町村の商工担当課、保証協会 |

金融機関は1行だけに絞らないほうが安全です。複数の金融機関と取引しておくと、1行の方針変更で資金繰りが詰まるリスクが下がります。

## 申込みから実行までの流れ

1. 金融機関に相談する（または市町村の商工担当課で制度を確認する）
2. 必要書類を揃える
3. 金融機関に申し込む
4. 金融機関が信用保証協会に保証を申し込む
5. 保証協会の審査（面談があることもあります）
6. 保証承諾
7. 金融機関の最終審査
8. 契約・実行

**審査が2回あります。** 保証協会と金融機関の両方です。このため、プロパー融資より時間がかかります。1か月程度を見ておいてください。

セーフティネット保証を使う場合は、これに市町村の認定手続きが加わります。

## 保証協会の審査で見られること

金融機関の審査と重なる部分もありますが、保証協会には独自の視点があります。

- 事業の実態があるか（実際に営業しているか）
- 資金使途が明確か
- 返済原資が見込めるか
- 既存の保証残高（保証限度額の枠）
- 税金の滞納がないか
- 代位弁済の履歴がないか

:::warn
**税金・社会保険料の滞納があると、保証が受けられません。** 納税証明書の提出を求められます。滞納がある場合は、まず分割納付の手続きを取り、履行している状態を作ってください。
:::

## 保証限度額

無担保での保証には限度額があります。普通保証と無担保保証の枠は別に設定されており、さらに特別な保証制度には別枠が設けられていることがあります。

既に保証付き融資を受けている場合、枠が残っているかを確認してください。枠がいっぱいだと、新たな保証付き融資は受けられません。

この場合の選択肢は、プロパー融資か、[日本政策金融公庫](/yushi/kouko-yushi/)になります。公庫の融資は保証協会の枠とは別です。

## 資金使途は守ってください

運転資金として借りたものを設備投資に使う、といった流用は契約違反です。

- 資金使途違反が判明すると、一括返済を求められることがあります
- 以後の取引に影響します

設備資金として借りる場合、見積書どおりの設備を購入したことを示す資料（領収書、納品書、写真）の提出を求められることがあります。

## 借換えと条件変更

### 借換え

複数の借入を1本にまとめ、月々の返済額を減らす方法です。

- 返済期間が延びるため、月々の負担は軽くなる
- 総支払利息は増える
- 保証料を再度払うことになる

資金繰りが厳しい場合の有効な手段ですが、根本的な収益改善が伴わないと、数年後に同じ状態になります。

### 条件変更（リスケジュール）

返済が困難になった場合、一定期間、元本の返済を猶予してもらう方法です。

:::point
**延滞する前に相談してください。** 無断で延滞すると信用を失います。「来月の返済が厳しい」と分かった時点で、金融機関に連絡してください。
:::

条件変更を行うと、その後しばらく新規融資は難しくなります。ただし、延滞して代位弁済に至るよりは、はるかに影響が小さく済みます。

条件変更を申し込む際は、**経営改善計画**の提出が求められます。どう収益を改善し、いつから返済を再開するかを示す必要があります。

## 経営改善計画に書くこと

1. 現状の分析（なぜ返済が困難になったか）
2. 改善の施策（具体的に何をするか）
3. 数値計画（3〜5年の売上・利益・資金繰り）
4. 返済計画（いつから、いくら返すか）

2番が具体的でないと通りません。「経費を削減する」ではなく、「通信費を見直して年30万円、保険を見直して年40万円削減する」という粒度が必要です。

[固定費の見直し](/cost/tsushinhi-sakugen/)と[法人保険の見直し](/cost/houjin-hoken-minaoshi/)で触れた内容が、そのまま使えます。

## 複数行取引の意味

1行だけと取引していると、その1行の方針が変わったときに資金繰りが詰まります。

- メインバンク（決済・給与振込・主要な借入）
- サブバンク（一部の借入、代替の確保）
- [日本政策金融公庫](/yushi/kouko-yushi/)（政策的な資金、創業・災害時）

この3層を持っておくと、1つが止まっても対応できます。

ただし、借りられるだけ借りるのは危険です。[返済原資](/yushi/shikinguri-kihon/)を超える借入は、資金繰りを圧迫します。

## 相談の前に用意しておくもの

[銀行が決算書のどこを見ているか](/yushi/ginko-kessansho/)で触れたとおり、次の資料を自分から出せると評価が変わります。

1. 直近の試算表
2. 資金繰り表（6か月〜1年）
3. 借入金一覧（金融機関別・残高・返済額・担保・保証）
4. 資金使途の明細（設備なら見積書）
5. 返済計画

3番は、複数行と取引している会社ほど重要です。金融機関は他行の状況を知りたがります。自分から開示すると、信頼につながります。
