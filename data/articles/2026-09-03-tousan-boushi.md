中小企業倒産防止共済（経営セーフティ共済）は、掛金が全額損金になるため、節税策として紹介されることが多い制度です。

ただし、**解約したときに解約手当金が収入になります**。税金がなくなるのではなく、払う時期が後ろにずれるだけです。

## 制度の内容

本来の目的は、取引先が倒産したときに資金を借りられるようにしておくことです。

| 項目 | 内容 |
|---|---|
| 掛金 | 月額5,000円〜200,000円（5,000円単位） |
| 掛金総額の上限 | 800万円 |
| 貸付限度額 | 掛金総額の10倍（最高8,000万円）と回収困難額のいずれか少ない額 |
| 税務上の扱い | 掛金は全額損金（法人）／必要経費（個人） |

前納制度があり、1年分（最大240万円）をまとめて払えば、その事業年度に全額を損金算入できます。決算前の利益調整に使われるのはこのためです。

## 解約したときにどうなるか

| 納付月数 | 戻る割合 |
|---|---|
| 12か月未満 | 0％（掛け捨て） |
| 12か月以上23か月以下 | 80％ |
| 24か月以上29か月以下 | 85％ |
| 30か月以上35か月以下 | 90％ |
| 36か月以上39か月以下 | 95％ |
| **40か月以上** | **100％** |

40か月（3年4か月）納めれば全額戻ります。ただし戻ってきた解約手当金は、その事業年度の**益金**になります。

800万円まで積んで解約すれば、その期に800万円の利益が上乗せされます。何も手を打たなければ、繰り延べた税金をまとめて払うことになります。

## 出口を先に決める

この制度を使うなら、解約する年に**同じ金額の損失や費用が出る**予定を組み合わせる必要があります。

よくある組み合わせ：

- **役員退職金**：社長の勇退時期に合わせて解約する
- **大規模な設備投資**：特別償却や即時償却と組み合わせる
- **赤字の年**：業績が落ち込んだ期に解約して補填する

3つ目は狙って作れるものではありませんが、設備投資や退職金は時期を計画できます。加入するときに「何年後に、何と組み合わせて解約するか」を決めておいてください。

:::warn
出口を決めずに積み続け、資金が必要になって解約した結果、その期に多額の税金が発生する。これがいちばん多い失敗です。
:::

## 令和6年10月の改正

**解約した後2年間は、再加入しても掛金を損金に算入できません。**

改正前は、解約してすぐ再加入し、また掛金を損金にするという使い方ができました。これが封じられています。

「決算のたびに解約と再加入を繰り返す」運用を前提にしている場合は、計画の見直しが必要です。

## 加入できる条件

継続して1年以上事業を行っている中小企業者が対象です。業種ごとに資本金または従業員数の基準があります。

| 業種 | 資本金 | または従業員数 |
|---|---|---|
| 製造業、建設業、運輸業その他 | 3億円以下 | 300人以下 |
| 卸売業 | 1億円以下 | 100人以下 |
| サービス業 | 5,000万円以下 | 100人以下 |
| 小売業 | 5,000万円以下 | 50人以下 |

個人事業主も加入できます。ただし、医療法人、農事組合法人、NPO法人などは対象外です。

## 小規模企業共済との違い

よく混同されますが、別の制度です。

| | 倒産防止共済 | 小規模企業共済 |
|---|---|---|
| 目的 | 取引先倒産時の資金手当て | 経営者の退職金 |
| 掛金を払うのは | 会社（法人の場合） | 経営者個人 |
| 税務上の扱い | 法人の損金 | 個人の所得控除 |
| 受取時 | 益金（法人） | 退職所得または雑所得 |
| 掛金の上限 | 月20万円 | 月7万円 |

小規模企業共済のほうは、受け取るときに退職所得として扱われるため、税負担が大きく軽くなります。**繰り延べではなく実質的な減税**になる点で性質が違います。

法人の利益を圧縮したいなら倒産防止共済、経営者個人の退職金を準備したいなら小規模企業共済、という使い分けになります。両方に入ることもできます。

## 貸付を受けられる場面

本来の機能は共済金の貸付です。取引先が倒産して売掛金などが回収困難になったとき、無担保・無保証人で借りられます。

**倒産と扱われる事由**

- 法的整理（破産、民事再生、会社更生、特別清算）
- 取引停止処分（手形交換所の参加金融機関による）
- でんさいネットの取引停止処分
- 私的整理（弁護士等による債務整理の通知）
- 災害による不渡り
- 特定非常災害による支払不能

:::warn
**夜逃げは対象外です。** 単に連絡が取れなくなった、事業をやめて音信不通になった、という状態では共済金の貸付を受けられません。法的な手続きが取られていることが必要です。
:::

中小企業の現場では、取引先が静かに事業を畳んで連絡が取れなくなるケースのほうが多く、この制度で救われる場面は限られます。加入の主目的が貸付なのか、損金算入なのかを整理しておいてください。

## 借りると掛金が減ります

共済金の貸付を受けると、**借入額の10分の1に相当する額が掛金総額から差し引かれます**。無利子ですが、実質的には掛金の1割を手数料として払う形です。

800万円積んで800万円借りると、80万円が掛金から消えます。この点は理解したうえで使ってください。

## 一時貸付金

取引先の倒産がなくても、解約手当金の範囲内で借りられる制度があります。事業資金として使えます。

金利は年0.9％程度（変動）で、掛金納付月数に応じて借入限度額が決まります。銀行融資より手続きが簡便なので、つなぎ資金として使えます。

ただし返済できないと、解約手当金から差し引かれます。

## 前納の扱い

掛金は前納できます。1年分（最大240万円）を決算月に払えば、その期の損金になります。

前納するときの注意点：

- **前納減額金**がわずかに戻ります（雑収入として計上）
- 翌期以降も同じ処理を続けるかどうかを決めておく
- 前納した期の翌期は、掛金の損金算入がゼロになる（すでに払っているため）

3番目を見落とすと、翌期に「今年は掛金の経費がない」と気づいて慌てることになります。毎期前納を続けるか、初年度だけにするかを先に決めてください。

## 申告書への添付が必要です

法人が掛金を損金算入する場合、**「特定の基金に対する負担金等の損金算入に関する明細書」（別表十(七)）の添付が必要**です。

個人事業主の場合は、確定申告書に「中小企業倒産防止共済掛金の必要経費算入に関する明細書」を添付します。

:::warn
添付を忘れると損金算入が認められません。申告をご自身で行っている場合は特に注意してください。
:::

## 加入の手続き

1. 商工会議所・商工会、金融機関、または中小機構の窓口で申込書を受け取る
2. 登記事項証明書（法人）または確定申告書の控え（個人）を用意する
3. 掛金の引落口座を指定する
4. 申込書を提出する

加入には**継続して1年以上の事業実績**が必要です。設立1年目の法人は加入できません。

## 小規模企業共済と組み合わせる

法人の利益を圧縮する倒産防止共済と、経営者個人の退職金を作る小規模企業共済は、目的が違うため両方に入れます。

| | 倒産防止共済 | 小規模企業共済 |
|---|---|---|
| 掛金の上限 | 月20万円（年240万円） | 月7万円（年84万円） |
| 誰の経費になるか | 法人 | 個人（所得控除） |
| 受取時の課税 | 益金 | 退職所得・公的年金等 |
| 実質的な効果 | 課税の繰り延べ | 税率差による減税 |

小規模企業共済のほうは、掛金が所得控除になり、受取時は退職所得として扱われます。退職所得は勤続年数に応じた控除があり、さらに2分の1課税なので、税負担が実質的に軽くなります。**繰り延べではなく減税**です。

資金に余裕があるなら、小規模企業共済を優先したほうが効率は良くなります。
