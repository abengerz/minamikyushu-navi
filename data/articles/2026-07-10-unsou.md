運送業には、他の業種にない2つの規制があります。

1. **時間外労働の上限規制**（労働基準法）… 年960時間
2. **改善基準告示**（厚生労働大臣告示）… 拘束時間・休息期間・運転時間

この2つは別の規制です。片方を守っていても、もう片方に違反することがあります。

## 時間外労働の上限

自動車運転の業務は、年960時間が上限です。

| | 一般の業種 | 自動車運転の業務 |
|---|---|---|
| 原則 | 月45時間・年360時間 | 同左 |
| 特別条項の上限 | 年720時間 | **年960時間** |
| 単月100時間未満 | 適用あり | 適用なし |
| 複数月平均80時間以内 | 適用あり | 適用なし |
| 月45時間超は年6回まで | 適用あり | 適用なし |

一般則より上限は高い一方、改善基準告示で拘束時間が厳しく制限されているため、実質的な余地は限られます。

[36協定](/roumu/36-kyotei-jogen/)の届出は必要です。様式は自動車運転者用のものを使います。

## 改善基準告示

拘束時間、休息期間、運転時間などが定められています。トラック（貨物自動車運送事業）の主な基準です。

| 項目 | 基準 |
|---|---|
| 1年の拘束時間 | 原則3,300時間（労使協定により最大3,400時間） |
| 1か月の拘束時間 | 原則284時間（労使協定により最大310時間） |
| 1日の拘束時間 | 原則13時間、最大15時間（14時間超は週2回までが目安） |
| 休息期間 | 継続11時間以上与えるよう努める。**9時間を下回らない** |
| 運転時間 | 2日平均で1日9時間、2週平均で1週44時間 |
| 連続運転時間 | 4時間以内（運転の中断は1回おおむね連続10分以上・合計30分以上） |

:::warn
**拘束時間には、運転していない待機時間も含まれます。** 荷待ち、荷役作業、点検、給油のすべてが拘束時間です。「走っている時間だけ」で管理していると、必ず超過します。
:::

バス・ハイヤー・タクシーには別の基準が定められています。

## 荷待ち時間が最大の課題

運送業の拘束時間が長くなる最大の原因は、荷主都合の待機です。

対応として、**荷待ち時間の記録**が求められています。一定の要件に該当する場合、乗務記録に荷待ち時間を記載する義務があります。

記録を残すことには2つの意味があります。

1. 自社の労働時間管理の根拠になる
2. **荷主との交渉材料になる**

荷主都合の長時間の荷待ちが続く場合、国土交通省の「荷主対策」の枠組みで、荷主への働きかけや要請が行われる制度があります。記録がなければ申し出ることもできません。

## 賃金体系の見直し

歩合給中心の賃金体系では、時間外割増の計算が複雑になります。

出来高払制の場合の割増賃金は、次の式になります。

> （その賃金算定期間の出来高払制の賃金総額 ÷ 総労働時間数）× 0.25 × 時間外労働時間数

**固定給部分の1.25倍とは計算が違い、0.25倍**です。二重払いにならないよう、賃金規程で明確にしてください。

{{tool:zangyo}}

また、2026年10月から[最低賃金が上がります](/roumu/saitei-chingin-2026/)。歩合給の場合も、総額を総労働時間で割った額が最低賃金を下回ってはいけません。

保障給（出来高払制の場合に一定額を保障する仕組み）の設定も確認してください。

## 点呼とデジタコ

運行管理では、次の記録が必要です。

- 点呼記録簿（乗務前・乗務後・中間点呼）
- 乗務記録（運転日報）
- 運行記録計（タコグラフ）の記録
- 車両の点検記録

紙での管理は集計に時間がかかります。デジタコと運行管理システムを入れると、拘束時間の集計が自動化されます。

これらの導入には[IT導入補助金](/hojokin/it-dounyu-hojokin/)や[業務改善助成金](/hojokin/gyomu-kaizen-joseikin-2026/)が使える場合があります。

## 人手不足への対応

宮崎・鹿児島は域外への輸送距離が長く、長距離運行が中心になりやすい地域です。ドライバーの確保が難しく、規制強化で1人あたりの稼働時間も減っています。

打ち手は限られます。

| 対応 | 内容 |
|---|---|
| 中継輸送 | 複数のドライバーで区間を分ける |
| モーダルシフト | 一部をフェリー・鉄道に移す |
| 積載効率の向上 | 帰り荷の確保、共同配送 |
| 運賃の適正化 | 標準的な運賃を根拠に交渉する |
| [採用](/roumu/kyujinhyo-kakikata/) | 求人票の条件を見直す |

運賃交渉では、原価を示せるかどうかが分かれ目です。車両ごとの原価（燃料、人件費、減価償却、保険、修繕）を出しておいてください。

[建設業の原価管理](/yushi/kensetsu-genka/)と同じ考え方です。工事番号の代わりに、車両番号・運行番号で原価を紐づけます。

## 確認すること

1. 拘束時間を月次で集計できているか（荷待ち時間を含めて）
2. 36協定の様式が自動車運転者用になっているか
3. 歩合給の割増賃金の計算式が正しいか
4. 荷待ち時間を記録しているか
5. 10月の最低賃金改定への対応

1番ができていない会社は、そこから着手してください。集計できていなければ、違反しているかどうかも分かりません。

## 拘束時間の集計方法

月次で集計できる状態を作ります。必要な項目です。

| 項目 | どこから取るか |
|---|---|
| 出庫時刻・帰庫時刻 | 点呼記録簿 |
| 運転時間 | タコグラフ |
| 荷待ち時間 | 乗務記録 |
| 荷役作業時間 | 乗務記録 |
| 休憩時間 | 乗務記録 |
| 中間点呼の有無 | 点呼記録簿 |

> 1日の拘束時間 ＝ 帰庫時刻 − 出庫時刻

これを1か月分合計したものが月間拘束時間です。**休憩時間も拘束時間に含まれます**（労働時間には含まれませんが、拘束時間には含まれます）。

紙で集計すると、ドライバー20名で月に十数時間かかります。デジタコと運行管理システムを連携させれば自動化できます。

## 休息期間の確保

勤務終了から次の勤務開始までの休息期間は、継続11時間以上与えるよう努めることとされ、**9時間を下回ってはいけません**。

長距離運行では、この9時間の確保が最大の制約になります。

対応策：

### 中継輸送

A地点からB地点まで1人で走るのではなく、中間地点でドライバーを交代します。

- それぞれの拘束時間が短くなる
- 日帰り運行にできる場合がある
- 中継拠点の確保と、相手方との調整が必要

九州内から関西・関東への輸送では、中継地点を設ける取組が広がっています。

### 2人乗務

2人で交代しながら運行する方式です。車両内の設備に一定の要件があります。

人件費は2倍になるため、運賃への反映が前提になります。

### フェリーの活用

フェリー乗船中の時間は、一定の条件のもとで休息期間として扱われる取扱いがあります。宮崎・鹿児島からの長距離輸送では、有力な選択肢です。

具体的な取扱いは改善基準告示とその解釈通達で定められているため、運用の前に運輸支局または労働基準監督署で確認してください。

## 運賃交渉の材料

「標準的な運賃」が国土交通省から告示されています。これは、適正な原価に適正な利潤を加えた運賃の目安を示すものです。

交渉では、自社の原価を示せるかどうかが分かれ目になります。

> 車両1台あたりの月間原価
>  ＝ 人件費（社会保険料込み）＋ 燃料費 ＋ 減価償却費 ＋ 修繕費
>    ＋ 保険料 ＋ 税金 ＋ 高速代 ＋ 一般管理費の配賦

この数字を運行距離や稼働時間で割ると、1kmあたり・1時間あたりの原価が出ます。

{{tool:shakai-hoken}}

社会保険料の会社負担を入れ忘れると、人件費を15％前後低く見積もることになります。

## 荷主との交渉

荷待ち時間の削減は、自社だけでは解決しません。

- 予約受付システムの導入を提案する
- 荷待ちの実績データを示す
- 納品時間の分散を提案する
- 附帯作業（荷役、検品）の対価を明確にする

最後の項目は見落とされがちです。運送以外の作業を無償で行っている場合、その分の対価を求める余地があります。契約書に附帯作業の範囲と対価を明記してください。

## 事故と保険

運送業は事故のリスクが高く、賠償額も大きくなります。

| 保険 | 対象 |
|---|---|
| 自賠責保険 | 対人賠償（法定） |
| 任意保険（対人・対物） | 法定を超える賠償 |
| 貨物保険 | 運送中の貨物の損害 |
| 荷主賠償責任保険 | 荷主に対する賠償 |
| 使用者賠償責任保険 | 従業員の労災に伴う上乗せ賠償 |

最後の項目は、労災保険の給付を超える賠償を請求された場合に備えるものです。過労運転による事故では、会社の安全配慮義務違反が問われることがあります。

[法人保険の見直し](/cost/houjin-hoken-minaoshi/)の際に、補償内容と限度額を確認してください。

## 健康起因事故への備え

運転者の健康状態に起因する事故が問題になっています。

- 定期健康診断の確実な実施
- 脳・心臓疾患のスクリーニング検査
- 睡眠時無呼吸症候群（SAS）のスクリーニング
- 点呼時の健康状態の確認と記録

健康診断を受けさせていない状態で事故が起きると、安全配慮義務違反が問われます。実施率は必ず100％にしてください。

[高年齢の従業員](/roumu/kourei-koyou/)が増えている業界でもあります。作業内容と健康状態の把握は、これまで以上に重要になっています。

## 補助金・助成金

| 制度 | 対象 |
|---|---|
| [業務改善助成金](/hojokin/gyomu-kaizen-joseikin-2026/) | 賃金引上げとセットでの設備導入 |
| [IT導入補助金](/hojokin/it-dounyu-hojokin/) | 運行管理・配車システム |
| 働き方改革推進支援助成金 | 労働時間の削減に取り組む中小企業 |
| 各種の環境対応補助 | 電動車両、省エネ設備 |

働き方改革推進支援助成金には、適用猶予業種等（建設業、運送業など）を対象としたコースが設けられることがあります。労働局で確認してください。

いずれも[交付決定前の発注は対象外](/hojokin/list/)です。順序に注意してください。
