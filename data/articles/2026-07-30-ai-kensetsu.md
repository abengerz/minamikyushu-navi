建設業は、現場の作業そのものはAIで置き換えられません。置き換えられるのは、**現場に出る前と後の書類作業**です。

宮崎・鹿児島の建設会社では、社長や工事部長が現場を見ながら書類も作っている、という体制が珍しくありません。ここに時間を取られると、現場の管理が薄くなります。

## 1. 見積書に添える説明文

見積書の数字は積算ソフトが出します。時間がかかるのは、施主向けの説明文のほうです。

とくにリフォームや改修工事では、「なぜこの工事が必要か」を説明しないと、金額だけを他社と比べられます。

### 指示の型

```
以下の条件で、施主向けの見積説明文を作ってください。

工事内容：[外壁塗装および付帯部塗装]
建物：[木造2階建て 築22年 延床115㎡]
面積：[外壁約130㎡]
金額：[128万円（税込）]
工期：[約14日]
現地調査で確認したこと：
 [・北面にカビと藻の発生
  ・シーリングの肥大化と切れが複数箇所
  ・軒天の一部に雨染み]

条件：
・専門用語は使わず、施主が読んで分かる表現にする
・金額の内訳ではなく、なぜその工事が必要かを説明する
・放置した場合に起きることに触れる
・不安を煽る表現は使わない
・400字程度
```

角括弧の中だけを毎回差し替えます。現地調査で確認したことを箇条書きで入れるのがポイントです。ここが具体的なほど、出てくる文章も具体的になります。

## 2. 安全書類・施工計画書の下書き

グリーンサイトなどで様式は決まっていますが、記述式の欄は毎回書く必要があります。

### 指示の型

```
以下の工事について、施工計画書の「安全管理」の章の下書きを作ってください。

工事名：[○○市営住宅 外壁改修工事]
工種：[外壁改修、足場仮設]
期間：[2026年10月〜12月]
現場の状況：[入居者が居住中。通学路に面している。隣地との離隔が狭い]
想定される危険：[墜落・転落、飛来落下、第三者災害、熱中症]

条件：
・想定される危険ごとに、具体的な対策を記載する
・「注意する」「徹底する」といった抽象的な表現は使わない
・誰が、何を、いつ行うかを書く
・法令上の根拠がある事項は、根拠を併記する
```

出力された内容は必ず確認してください。**法令の条番号はAIが誤ることがあります。** 根拠条文は自分で確認するか、確認したうえで使ってください。

## 3. 工程表の説明文・週間工程の共有

工程表そのものは専用ソフトで作りますが、それを協力会社や施主に説明する文章は別に必要です。

### 指示の型

```
以下の工程を、協力会社向けの週間連絡文にしてください。

今週の作業：
[月 足場組立
 火 高圧洗浄
 水 予備日（雨天順延分）
 木 下地補修
 金 養生・下塗り]

注意事項：
[・水曜は小学校の行事があり、8時〜9時は車両の出入りを止める
 ・木曜から隣家の駐車場を借りる（挨拶済み）]

条件：
・箇条書きで簡潔に
・日ごとの入場業者と作業内容が分かるように
・注意事項は目立つように書く
```

## そのほか使える場面

| 業務 | 効果 |
|---|---|
| 施主へのお礼状・完了報告 | 1件20分 → 3分 |
| 近隣への工事案内文 | 1件30分 → 5分 |
| 助成金・補助金の申請書の下書き | 数日短縮 |
| 求人票の文面 | [書き方](/roumu/kyujinhyo-kakikata/)の型と組み合わせる |
| 現場報告書 | [音声メモから整形](/ai/ai-gijiroku/) |
| 社内向けの安全衛生教育の資料 | 半日 → 1時間 |

補助金の申請書は効果が大きい部分です。[ものづくり補助金](/hojokin/monodukuri-hojokin/)や[業務改善助成金](/hojokin/gyomu-kaizen-joseikin-2026/)の計画書は文章量が多く、社長が夜に書いていることが多い書類です。

ただし、**数値と要件は必ず自分で確認してください**。AIは補助金の要件を正確には把握していません。構成と文章の整形に使い、中身は自分で埋めるという使い方になります。

## 入力してはいけないもの

建設業で特に注意すべき情報です。

- **元請から預かった図面・仕様書**（秘密保持条項に反する可能性）
- 公共工事の設計図書
- 発注者の個人情報（施主の氏名・住所・連絡先）
- 積算の内訳（自社の原価情報）
- 協力会社の単価表

元請との契約書に秘密保持の条項があるかを確認してください。公共工事では通常入っています。

詳しくは[AIに顧客データを入れてよいか](/ai/ai-kokyaku-data/)を参照してください。

## 始め方

1. 上の3つのうち、いちばん時間を取られているものを1つ選ぶ
2. 型をテキストファイルに保存して、共有フォルダに置く
3. 2週間、その業務だけAIで作る
4. 作成時間を記録する
5. 効果が出たら、次の業務に広げる

一度に全部やろうとすると続きません。1業務ずつです。

## 費用と補助金

法人向けのAIサービスは、1アカウント月数千円程度です。事務作業が月10時間減れば、時給1,500円換算で15,000円の効果になります。

システムの導入とセットであれば[IT導入補助金](/hojokin/it-dounyu-hojokin/)の対象になる場合があります。ただしAIサービス単体では対象になりにくいため、業務システムと組み合わせた構成で検討してください。

## 出力を確認するときの観点

AIの文章をそのまま使うと事故が起きます。確認する点を決めておいてください。

| 文書 | 必ず確認する箇所 |
|---|---|
| 見積説明文 | 金額、工期、工事範囲。「含む」「含まない」の表現 |
| 施工計画書 | 法令の条番号、有資格者の配置、点検の頻度 |
| 近隣への案内 | 日時、連絡先、担当者名 |
| 工程の連絡文 | 日付と曜日の対応、入場業者名 |

:::warn
法令の条番号は特に注意してください。労働安全衛生規則の条番号など、もっともらしい数字が出力されることがあります。根拠条文を書く場合は、必ず自分で確認してください。
:::

## 積算・原価はAIの仕事ではありません

数量の拾い、単価の掛け合わせ、原価管理。これらは積算ソフトと原価管理システムの領域です。AIに計算させないでください。

AIが得意なのは文章であって、計算ではありません。金額の計算をさせると、桁を間違えた結果が自然な文章で出てきます。

数字は必ずソフトで計算し、その結果を文章にする部分だけAIに任せてください。

## 現場の写真整理

工事写真の整理は、専用の写真管理ソフトを使ってください。電子納品の要領に沿った命名・分類が必要なため、汎用のAIでは対応できません。

一方、**写真に添える説明文**は定型なので、型を作れます。

```
以下の工事写真について、工事写真帳の説明文を作ってください。

工種：[外壁シーリング打替え]
撮影内容：[既存シーリング撤去後の目地清掃状況]
測点・位置：[北面 2階 X通り]

条件：
・簡潔に一文で
・「〜状況」で終わる形式
・寸法や数量は記載しない
```

## 若手への指導に使う

ベテランの社長が持っている判断を、文章にして共有する使い方があります。

```
以下の状況で、若手の現場代理人に説明する文章を作ってください。

状況：[梅雨時期の外部塗装。湿度が高く、下塗りの乾燥が遅れている]
判断：[施工を中止し、翌日以降に順延する]
理由：[湿度85％を超えると塗膜に不具合が出る。無理に塗ると数年で剥離する]

条件：
・なぜその判断になるかを、理由から説明する
・叱責調にしない
・300字程度
```

社長が口頭で説明していることを文章にすると、次に同じ状況が来たときに読み返せます。数を貯めれば社内マニュアルになります。

## 導入の順序

建設会社で進めるときの現実的な順番です。

1. **事務担当者が1人で試す**（見積説明文から）
2. 2週間、時間を記録する
3. 効果が出たら、型を共有フォルダに置く
4. 工事部の1〜2名に広げる
5. 安全書類・現場報告に範囲を広げる
6. 入力してよい情報の範囲を1枚で配る

5番まで来たら、ルールを明文化してください。それまでは試行段階なので、使う人を限定し、社外に出す文書には使わない運用にします。

## 人手不足への効き方

建設業の人手不足は、現場の職人だけでなく事務方にも及んでいます。事務員を1人採用するのに[求人費用と数か月](/roumu/kyujinhyo-kakikata/)かかる一方、既存の担当者の事務時間を月20時間減らせれば、それだけで4分の1人分に相当します。

2026年10月には[最低賃金が上がります](/roumu/saitei-chingin-2026/)。宮崎県1,085円、鹿児島県1,090円です。人件費が上がる分を、事務作業の削減で吸収する組み立てが現実的です。
