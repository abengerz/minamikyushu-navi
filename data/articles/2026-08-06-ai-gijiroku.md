文章作成のなかで、いちばん効果が出やすいのが議事録です。理由は3つあります。

1. 元になる情報（発言）が揃っている
2. 出力の形式が毎回同じ
3. 作るのに時間がかかっている割に、誰も作りたがらない

## 全体の流れ

1. 会議を録音する
2. 文字起こしする
3. AIで整形する
4. 人が確認して直す

3までが自動化できる部分です。4は必ず人がやります。

## 1. 録音する

スマートフォンの録音アプリで足ります。専用機材は不要です。

ポイントは**マイクを会議の中心に置く**ことです。端に置くと遠い席の声が拾えず、文字起こしの精度が落ちます。

:::warn
録音することを参加者に伝えてください。黙って録音すると、後で問題になります。「議事録作成のために録音します」と冒頭で一言添えれば足ります。社外の人が参加する場合は特に必要です。
:::

## 2. 文字起こし

文字起こしの方法は複数あります。

- スマートフォンの文字起こし機能
- 文字起こし専用サービス
- Web会議ツールの録画・文字起こし機能
- AIサービスの音声入力

Web会議であれば、ツール側に文字起こし機能があることが多いので、まずそれを確認してください。追加のサービスが不要になります。

対面の会議では、スマートフォンで録音したファイルを文字起こしサービスに入れる形になります。

この段階の出力は、読める文章にはなっていません。「えー」「あの」が入り、誰の発言か分からず、話が前後します。それで構いません。

## 3. AIで整形する

ここで型を使います。毎回コピーして、文字起こしのテキストを貼り付けるだけです。

```
以下は会議の文字起こしです。議事録に整形してください。

【出力の形式】
■ 日時・場所・出席者
■ 決定事項（箇条書き。決まったことだけ）
■ 保留事項（結論が出なかったこと、次回持ち越し）
■ ToDo（担当者と期限。期限が不明なものは「期限未定」と記載）
■ 議論の要旨（300字程度）

【指示】
・発言者名が分かる場合は決定事項に含める
・言い淀み、相槌、雑談は除く
・文字起こしに含まれていない内容を補わない
・不明な点は「（要確認）」と記載する

【文字起こし】
（ここに貼り付け）
```

最後の2つの指示が重要です。これを書かないと、AIが文脈から推測して事実でないことを書きます。

## 4. 人が確認する

必ず確認してください。特に次の点です。

- 金額、日付、数量が正しいか
- 決定事項が実際の決定と合っているか
- 担当者の割り当てが正しいか
- 「（要確認）」の箇所を埋める

数字は聞き間違い・変換間違いが起きやすい部分です。「250万円」が「２５０万円」「25万円」になっていることがあります。

## ほかの文書にも使える

同じ型で、形式を変えるだけです。

### 現場報告書（建設業）

```
以下は現場からの音声メモです。報告書に整形してください。

【出力の形式】
■ 現場名・日付・天候
■ 本日の作業内容
■ 進捗（予定に対して）
■ 課題・問題点
■ 翌日の予定
■ 安全に関する特記事項

【指示】
・音声メモにない内容を補わない
・数量、寸法は音声のとおりに記載し、不明瞭なら「（要確認）」
```

現場で音声メモを吹き込んでおけば、事務所に戻ってから書く作業がなくなります。

### 顧客訪問の記録（営業）

```
以下は訪問後の音声メモです。訪問記録に整形してください。

■ 訪問先・日時・面談者
■ 先方の要望
■ 提示した内容
■ 次のアクション（自社側・先方側）
■ 次回訪問の予定

【指示】
・先方の発言と自社の説明を区別する
・金額は音声のとおりに記載する
```

移動中に音声メモを取れば、帰社後の入力が消えます。

### 電話メモ

```
以下は電話の内容です。共有用のメモに整形してください。

■ 相手（会社名・氏名）
■ 用件
■ 回答した内容
■ 引き継ぎ事項（誰が、何を、いつまでに）
```

## 入力してよい情報の範囲

顧客名や個人名が含まれる場合、社内のルールを確認してください。

[AIに顧客データを入れてよいか](/ai/ai-kokyaku-data/)で整理したとおり、契約しているプランの規約、取引先とのNDA、個人情報の扱いを確認したうえで運用します。

迷う場合は、固有名詞を「A社」「B様」に置き換えてから入力し、出力後に戻す運用にしてください。置き換えの手間は数十秒です。

## 効果を測る

導入前と導入後で、1件あたりの作成時間を記録してください。

| | 従来 | 導入後 |
|---|---|---|
| 会議の議事録（60分の会議） | 45分 | 10分 |
| 現場報告書 | 20分 | 5分 |
| 訪問記録 | 15分 | 3分 |

週に議事録3件、報告書10件なら、月あたり10時間程度の削減になります。

測っていないと、次の業務に広げる判断ができません。[AIの定着](/ai/ai-dounyu-teichaku/)で書いたとおり、効果を数字で確認してから範囲を広げてください。

## 精度を上げる工夫

### 冒頭で出席者を読み上げる

会議の最初に「本日は○○、△△、××の3名です」と口頭で入れておくと、AIが発言者を推定しやすくなります。

### 固有名詞を事前に伝える

社名、商品名、専門用語は誤変換されます。型に「用語集」を足してください。

```
【正しい表記の用語】
・○○工業（おーまるこうぎょう）
・□□システム
・ロット（製造の単位）
・歩掛（ぶがかり）
```

これを指示に含めると、変換のぶれが減ります。

### 会議を構造化して進める

議事録を作りやすい会議は、そもそも議論が整理されています。

- 冒頭に議題を読み上げる
- 議題ごとに「これで決定でよいですか」と確認する
- 最後にToDoを口頭で確認する

3番目を習慣にすると、文字起こしにToDoが明示的に残るため、AIの整形精度が上がります。会議そのものの質も上がります。

## 定型文書のテンプレート化

議事録で効果を確認したら、ほかの定型文書にも同じ方法を広げます。

| 文書 | 元になる情報 | 効果 |
|---|---|---|
| 見積書の説明文 | 工事内容・現地の状況 | 1件30分 → 5分 |
| 請求書の添え状 | 請求内容 | 1件10分 → 1分 |
| 採用の不採用通知 | 応募者情報 | 1件10分 → 2分 |
| 取引先への価格改定通知 | 改定内容と理由 | 1件60分 → 10分 |
| 社内の規程改定の説明文 | 改定内容 | 1件90分 → 15分 |

価格改定の通知は、書くのに時間がかかるうえに文面を誤ると関係に影響する文書です。AIに複数案を出させて、そこから選ぶ使い方が向いています。

## 使ってはいけない場面

判断そのものをAIに委ねないでください。

- 懲戒処分の妥当性の判断
- 解雇の可否
- 税務上の取扱いの結論
- 契約書の条項の有効性
- 補助金の要件を満たすかの判断

これらは、AIの出力が自信ありげに間違っていることがあります。文章の整形と下書きにとどめ、結論は専門家か一次情報で確認してください。

[問題社員への対応](/risk/mondai-shain/)のような場面では、記録の整形にはAIが使えますが、処分の判断は別です。

## 保存と共有

作った議事録の保管場所を決めてください。

- 共有フォルダに、年月日と会議名でファイル名を付けて保存する
- 決定事項だけを別途一覧にしておく

2番目が効きます。議事録を全部読み返す人はいませんが、「決定事項の一覧」は参照されます。

なお、電子データでやり取りした取引情報は[電子帳簿保存法](/zeimu/denshi-chobo-hozon/)の対象になりますが、社内の議事録は対象ではありません。保存義務は会社法・税法上の帳簿書類とは別の話です。

## まず1週間試す

導入を決める前に、1週間だけ試してください。

1. 今週の会議を1つ録音する
2. 文字起こしする
3. 上の型でAIに整形させる
4. 従来の方法で作った場合の時間と比べる

効果が出なければやめればよいだけです。全社導入を決める前に、1人が1業務で試すのが最も安全です。
