宮崎・鹿児島は畜産・園芸・茶・さつまいもなど農業の比重が大きい地域です。農業には、一般の事業と違う取扱いがいくつかあります。

## 青色申告の特典

農業も青色申告ができます。個人の場合の主な特典です。

| 特典 | 内容 |
|---|---|
| 青色申告特別控除 | 最大65万円（e-Taxまたは電子帳簿保存＋複式簿記） |
| 純損失の繰越控除 | 赤字を3年間繰り越せる |
| 純損失の繰戻還付 | 前年の所得税の還付を受けられる |
| 青色事業専従者給与 | 家族への給与を必要経費にできる |
| 少額減価償却資産の特例 | 一定額未満の資産を一括で経費にできる |

天候で収穫が左右される農業では、**赤字の繰越しと繰戻しが特に効きます**。台風や干ばつで大きく落ち込んだ年の損失を、他の年と通算できます。

[開業時の届出](/zeimu/kaigyo-tetsuzuki/)で触れたとおり、青色申告承認申請書には期限があります。

## 家族への給与

農業は家族経営が多く、配偶者や子が働いているのが通常です。

### 青色事業専従者給与

青色申告の場合、次の要件を満たせば必要経費になります。

1. 生計を一にする配偶者その他の親族であること
2. その年12月31日現在で15歳以上であること
3. 年間6か月を超えて事業に専ら従事していること
4. **「青色事業専従者給与に関する届出書」を提出していること**
5. 届出の範囲内で、労務の対価として適正な額であること

3番の「専ら従事」は、他に本業がある場合は認められません。会社員として働きながら週末だけ手伝う、という形では該当しません。

5番の適正額は、同じ仕事を第三者に頼んだ場合の金額が基準です。実態に比べて高すぎる給与は否認されます。

:::warn
届出をしていない年は経費になりません。また、届け出た金額を超えて支給した部分も経費になりません。金額を上げる場合は変更届を出してください。
:::

### 白色申告の場合

事業専従者控除として、配偶者は最高86万円、その他の親族は最高50万円の控除があります（ただし、事業所得等を専従者の数に1を足した数で割った金額が上限）。

青色申告のほうが有利になることがほとんどです。

## 収穫期の短期雇用

収穫・選果の時期に短期のパートを雇うケースです。

### 最低賃金は適用されます

農業は労働基準法第41条により、**労働時間・休憩・休日の規定が適用除外**とされています。ただし、これは残業代の規定が適用されないという意味であり、**最低賃金は適用されます**。

2026年10月から、宮崎県1,085円、鹿児島県1,090円です。

{{tool:saitei-chingin}}

:::point
なお、**深夜割増（22時〜5時）は農業でも適用されます**。適用除外は労働時間・休憩・休日の規定であって、深夜業の割増賃金は除外されていません。
:::

### 社会保険の加入

| 制度 | 個人事業（農業） | 法人（農事組合法人・株式会社） |
|---|---|---|
| 健康保険・厚生年金 | 任意適用（従業員5人以上でも農業は強制適用業種ではない） | 強制適用 |
| 労災保険 | 一定の場合に加入義務 | 加入義務 |
| 雇用保険 | 週20時間以上・31日以上の雇用見込みで加入 | 同左 |

個人経営の農業は、社会保険の強制適用業種ではありません。ただし従業員の半数以上の同意があれば任意適用事業所になれます。

**法人化すると強制適用**になります。法人化を検討する際は、社会保険料の負担も試算してください。

{{tool:shakai-hoken}}

### 労災保険

農業の労災は、規模や作業内容によって扱いが分かれます。特定の機械を使用する場合や、常時使用労働者数が一定以上の場合は強制加入です。

強制加入でない場合も、**特別加入**の制度があります。経営者自身や家族従事者が加入できます。農業機械による事故は重篤になりやすいため、加入を検討してください。

## 農業特有の制度

| 制度 | 内容 |
|---|---|
| 農業経営基盤強化準備金 | 交付金等を積み立てて損金算入し、後で農用地・農業用機械の取得に充てる |
| 収入保険 | 青色申告が要件。収入減少を補填する |
| 農業次世代人材投資資金 | 新規就農者への交付金 |
| 農地の相続税・贈与税の納税猶予 | 一定の要件で猶予 |

**収入保険は青色申告が加入要件**です。この点からも青色申告を選ぶ意味があります。

農業経営基盤強化準備金は、交付金を受けた年に積み立てて損金算入し、翌年以降に機械等を取得したときに取り崩す仕組みです。制度の要件が細かいため、適用にあたっては確認が必要です。

## 消費税の事業区分

簡易課税を選ぶ場合の区分です。

| 取扱い | 事業区分 | みなし仕入率 |
|---|---|---|
| 飲食料品の譲渡に係る農業 | 第2種 | 80％ |
| 飲食料品以外（花き、飼料、種苗など） | 第3種 | 70％ |

軽減税率の対象になる飲食料品を販売する農業は第2種、それ以外は第3種です。両方を扱う場合は区分して記録してください。

[簡易課税と一般課税の選び方](/zeimu/kanien-kazei-erabikata/)を参照してください。

## 補助金

農業向けの補助金は、農林水産省と各県の制度が中心です。

- 強い農業づくり総合支援交付金
- 産地生産基盤パワーアップ事業
- 各県・市町村の独自補助（施設整備、機械導入）

宮崎県・鹿児島県の独自制度は[県別のページ](/miyazaki/)から確認できます。

また、加工・販売まで行う場合（6次産業化）は、[ものづくり補助金](/hojokin/monodukuri-hojokin/)や[小規模事業者持続化補助金](/hojokin/jizokuka-hojokin/)の対象になることがあります。

## AIの使いどころ

[AIの活用](/ai/ai-dounyu-teichaku/)で挙げたとおり、農業では次の場面で効果が出ています。

- 補助金の申請書の下書き（文章量が多く、夜に書いている書類です）
- 出荷記録・作業日誌の整理
- 販売先への提案文、商品説明
- 病害虫の症状から可能性を絞る（最終判断は普及指導員や農協へ）

最後の項目は、あくまで当たりを付けるための使い方です。防除の判断は専門機関に確認してください。

## 法人化の判断

農業も法人化できます。農地所有適格法人（旧・農業生産法人）と、農地を所有しない一般の法人があります。

| | 個人経営 | 農業法人 |
|---|---|---|
| 所得税・法人税 | 累進課税 | ほぼ一定の税率 |
| 社会保険 | 原則任意 | **強制加入** |
| 赤字の繰越し | 3年 | 10年 |
| 家族への給与 | 青色事業専従者給与（届出が必要） | 通常の給与として支給できる |
| 退職金 | 支給できない | 支給できる（損金算入） |
| 信用 | — | 取引・融資・採用で有利になることがある |
| 農地の取得 | 個人として取得 | 農地所有適格法人の要件を満たす必要がある |

法人化のメリットが大きいのは、**所得が継続的に高い場合**と、**事業承継を考えている場合**です。

法人にすれば、代表者が交代しても法人格は続きます。農地や機械の名義を移す必要がなく、承継が容易になります。

一方、社会保険が強制適用になるため、従業員数が多いと負担が増えます。試算してから判断してください。

## 固定資産と減価償却

農業は設備投資の金額が大きい事業です。

| 資産 | 法定耐用年数の例 |
|---|---|
| 農業用ハウス（金属造） | 構造により14年など |
| 温室（ガラス造） | 構造による |
| 乾燥機 | 機械装置の区分による |
| トラクター | 7年（農業用設備） |
| 育成中の果樹・牛 | 成熟後に減価償却を開始 |

**果樹や乳牛は、成熟するまでは減価償却しません。** 育成にかかった費用を資産に計上し、成熟後に償却を始めます。この処理をしていないと、費用の計上時期がずれます。

中小企業経営強化税制や中小企業投資促進税制の対象になる設備もあります。即時償却や税額控除が使える場合があるため、[決算対策](/zeimu/kessan-setsuzei/)とあわせて検討してください。

## 天候リスクへの備え

宮崎・鹿児島は台風と豪雨の常襲地域です。

| 制度 | 内容 |
|---|---|
| 収入保険 | 収入減少を補填。**青色申告が要件** |
| 農業共済（NOSAI） | 災害による損失を補償 |
| 園芸施設共済 | ハウス等の被害を補償 |
| [災害復旧貸付](/yushi/kouko-yushi/) | 日本政策金融公庫（農林水産事業） |

収入保険と農業共済は、どちらか一方を選ぶ制度です（同一品目での重複加入はできません）。

- 収入保険：品目を問わず、収入全体の減少を補填。青色申告が必要
- 農業共済：品目ごとの被害を補償

複数品目を作っている経営体では、収入保険のほうが合うことが多くなります。

:::point
**被災したら、片付ける前に写真を撮ってください。** 被害の程度を示す証拠になります。共済の請求、罹災証明の申請、災害復旧補助のいずれでも必要になります。
:::

## 補助金の申請

農業関係の補助金は、申請書類の分量が多いのが特徴です。

- 経営体育成支援、産地パワーアップ事業などの国の事業
- 県・市町村の独自補助（施設整備、機械導入、新規就農）
- [ものづくり補助金](/hojokin/monodukuri-hojokin/)（6次産業化、加工設備）
- [小規模事業者持続化補助金](/hojokin/jizokuka-hojokin/)（直販、EC、パッケージ）

国の農業補助は、多くが市町村・県・農協を通じた要望取りまとめから始まります。**募集の時期が決まっている**ため、年間のスケジュールを把握しておく必要があります。

市町村の農政担当課と農協に、年1回は相談に行ってください。

## 販売先の多角化

農協出荷が中心の経営体でも、直販やECを組み合わせると単価が上がります。

| 販路 | 特徴 |
|---|---|
| 農協出荷 | 手間がかからない。単価は市況による |
| 直売所 | 手数料が低い。持ち込みの手間がある |
| EC・ふるさと納税 | 単価が高い。梱包・発送の手間 |
| 飲食店・小売への直接取引 | 単価が安定。営業と請求の手間 |
| 加工・6次産業化 | 付加価値が高い。設備投資が必要 |

直販を始めると、請求・発送・問い合わせ対応といった事務作業が増えます。ここは[AIと仕組み化](/ai/backoffice-dx/)で吸収できる部分です。

商品説明、SNS投稿、顧客への案内文は、型を作れば毎回の作成時間が大きく減ります。

## 消費税と直販

直販を始めると、課税売上が増えます。

- 基準期間の課税売上高が1,000万円を超えると、課税事業者になります
- ふるさと納税の返礼品も課税売上です
- 農協出荷分も課税売上です（軽減税率8％）

免税事業者のままでいられると思っていたら課税事業者になっていた、というケースがあります。年間の課税売上高を把握してください。

[簡易課税と一般課税の選び方](/zeimu/kanien-kazei-erabikata/)も参照してください。農業は第2種または第3種で、みなし仕入率が比較的高く設定されています。

## 事業承継

農業の承継では、農地の扱いが論点になります。

- 農地の贈与税・相続税の**納税猶予**制度がある
- 猶予を受けるには、営農を継続する必要がある
- 農地の権利移動には農業委員会の許可が必要

納税猶予は要件の継続が前提です。途中で営農をやめると、猶予されていた税額と利子税を納めることになります。

[事業承継の記事](/yushi/jigyo-shokei/)で触れた一般的な論点に加えて、農地特有の手続きがあります。農業委員会と税理士の両方に相談してください。
