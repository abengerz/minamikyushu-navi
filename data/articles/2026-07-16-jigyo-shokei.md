事業承継の相談で最初に聞くのは「誰に渡すか」ではありません。「**渡せる状態か**」です。

後継者が決まっていても、次の4つが片付いていないと実際には渡せません。

1. 自社株が分散している、または評価が高すぎる
2. 経営者個人の保証がついている
3. 経営者しか知らない業務がある
4. 役員貸付金や個人資産と会社資産が混在している

## 1. 自社株の整理

### 分散している場合

創業時に親族や従業員に株を持たせているケースがあります。相続が重なると、さらに分散します。

分散していると、後継者が経営判断をするたびに他の株主の同意が必要になります。重要な決議には3分の2以上の賛成が要るため、後継者の持分が3分の2に届かないと機動的に動けません。

対策：

- 買い取る（会社が自己株式として取得する、または後継者が買う）
- 種類株式（議決権制限株式）を使う
- 株主間契約を結ぶ

買い取る場合、買取価格でもめることがあります。早い段階、株価が低いうちに整理するほうが安く済みます。

### 評価が高い場合

利益が積み上がっている会社ほど、自社株の評価が高くなります。後継者が相続・贈与を受けると、多額の税金がかかります。

対策：

- 役員退職金を支給して純資産を減らす（[役員報酬の記事](/zeimu/yakuin-hoshu-kimekata/)参照）
- 生前贈与を計画的に行う
- 事業承継税制（納税猶予）を使う

**事業承継税制**は、一定の要件を満たすと自社株にかかる相続税・贈与税の納付が猶予される制度です。特例措置には適用期限があり、事前に特例承継計画の提出が必要です。要件と期限は必ず最新の情報で確認してください。

:::warn
納税猶予は「免除」ではありません。要件を満たさなくなると、猶予されていた税額と利子税を納めることになります。雇用の維持、株式の保有継続などの条件が続くため、長期にわたる管理が必要です。
:::

## 2. 個人保証の解除

借入に経営者の個人保証がついていると、後継者が同じ保証を引き継ぐことになります。これを理由に承継を断られるケースがあります。

「経営者保証に関するガイドライン」では、次の要件を満たす場合に保証を求めない、または解除を検討することとされています。

1. **法人と経営者個人の資産・経理が明確に分離されている**
2. 法人のみの資産・収益力で返済が可能である
3. 金融機関に対し、適時適切に財務情報が開示されている

1番が最大の壁です。役員貸付金がある、社長の個人的な支出を会社で払っている、会社名義の不動産に社長が住んでいる。こうした状態があると、分離されていないと判断されます。

解除の交渉は数年かかります。**承継を考え始めた時点で、金融機関に相談してください。**

[銀行が決算書のどこを見ているか](/yushi/ginko-kessansho/)で触れたとおり、役員貸付金は評価を落とす代表的な科目です。

## 3. 業務の属人化を解く

社長しか知らないことが多いほど、承継は難しくなります。

洗い出すべきもの：

| 項目 | 確認 |
|---|---|
| 取引先との関係 | 社長個人の信頼で続いている取引はどれか |
| 価格の決め方 | 見積の根拠、値引きの判断基準 |
| 仕入先の選定 | なぜその業者なのか |
| 資金繰りの管理 | 誰がいつ何を見ているか |
| 許認可 | 名義、更新時期、必要な資格者 |
| 銀行との関係 | 担当者、これまでの経緯 |
| 保険の内容 | 何のために入ったか |

許認可は特に注意が必要です。建設業許可の経営業務の管理責任者、宅建業の専任宅地建物取引士など、**特定の人がいないと許可が維持できない**業種があります。

後継者が要件を満たすまでに時間がかかる場合、その期間を逆算して育成を始める必要があります。

## 4. 個人資産と会社資産の分離

- 会社名義の車を社長が私用で使っている
- 社長個人名義の土地に会社の建物が建っている
- 会社名義の不動産に社長が住んでいる
- 役員貸付金・役員借入金がある

これらは承継の際に必ず論点になります。個人保証の解除にも影響します。

役員借入金（社長が会社に貸しているお金）は、相続財産になります。回収できない状態で相続が発生すると、価値のない債権に相続税がかかることがあります。

## 後継者がいない場合

### M&A（第三者への譲渡）

近年、中小企業のM&Aは珍しくなくなっています。

- 従業員の雇用が維持される
- 取引先との関係が続く
- 経営者に譲渡対価が入る

各県に**事業承継・引継ぎ支援センター**があり、無料で相談できます。まずここに行ってください。民間の仲介会社に直接相談する前に、公的機関で全体像を把握するほうが安全です。

仲介手数料の体系は会社によって大きく違います。着手金、中間金、成功報酬の有無と料率を必ず書面で確認してください。

### 従業員への承継

役員や従業員が引き継ぐ形です。

課題は資金です。株を買い取る資金を後継者が用意できないことが多く、金融機関からの借入や、持株会社を使うスキームが検討されます。

事業承継・集約・活性化支援資金など、専用の融資制度があります。

### 廃業

選択肢の1つです。ただし「何もせずに閉じる」と、手元に残る資産が少なくなります。

- 在庫、設備の処分にかかる費用
- 原状回復費用
- 従業員への退職金
- 借入金の返済
- 許認可の廃止手続き

計画的に進めれば、設備の売却や、取引先・従業員の引き継ぎ先を探す時間が取れます。急に閉じるより、明らかに条件が良くなります。

## 進め方の目安

| 時期 | やること |
|---|---|
| 10年前 | 後継者候補を決める。自社株の評価を把握する |
| 7年前 | 後継者を社内の要職に就ける。許認可の要件を確認する |
| 5年前 | 株の移転を開始する。個人保証の解除を相談する |
| 3年前 | 取引先・金融機関に紹介する。業務の引き継ぎを進める |
| 1年前 | 代表権の移転時期を決める。役員退職金の準備 |
| 承継 | 登記、届出、取引先への通知 |

**現経営者が急に倒れた場合に備えて、最低限の情報だけでも今すぐ書き出してください。** 取引銀行と担当者、借入の一覧、保険の契約先、許認可の内容、重要な取引先の連絡先。これだけでも1枚にまとめておくと、万一のときに会社が止まりません。

## 後継者の育成

株や保証の整理と同じくらい時間がかかるのが、後継者の育成です。

### 社内での経験

- 現場を経験させる（技術・営業の実務）
- 数字を見る習慣をつけさせる（月次の試算表、資金繰り表）
- 金融機関との面談に同席させる
- 取引先への挨拶回りに同行させる

**数字を見る習慣**が最も重要です。決算書の読み方が分からないまま社長になると、判断ができません。

月次の数字を一緒に見る時間を、定期的に取ってください。[銀行が決算書のどこを見ているか](/yushi/ginko-kessansho/)を一緒に確認するだけでも意味があります。

### 外部での経験

同業他社や取引先で数年働かせる方法もあります。

- 他社のやり方を知る
- 社内で「社長の息子」として扱われない期間ができる
- 人脈ができる

戻ってきたときに、社内の従業員が受け入れやすくなる効果もあります。

### 社内の合意形成

後継者を決めたら、従業員に早めに伝えてください。突然の発表は反発を招きます。

古参の従業員との関係は、承継の成否を分けます。後継者より社歴の長い従業員がいる場合、その人の処遇と役割を先に決めておいてください。

## 承継の方法

| 方法 | 内容 | 税務上の扱い |
|---|---|---|
| 生前贈与 | 生きているうちに株を渡す | 贈与税（暦年課税または相続時精算課税） |
| 相続 | 死亡により承継 | 相続税 |
| 売買 | 後継者が買い取る | 譲渡所得（売主）。後継者に資金が必要 |
| 事業承継税制 | 贈与・相続の納税を猶予 | 要件充足の継続が必要 |

### 暦年課税と相続時精算課税

生前贈与では、どちらの課税方式を使うかで結果が変わります。

- **暦年課税**：年間の基礎控除の範囲で毎年少しずつ渡す。長期間かけられる場合に有効
- **相続時精算課税**：一定額まで贈与税がかからないが、相続時に精算される

株価が今後上がる見込みなら、低いうちに渡すほうが有利になります。逆に下がる見込みなら急ぐ必要はありません。

制度の内容は改正されているため、実行前に必ず現行の要件を確認してください。

## 遺留分への配慮

後継者に株を集中させると、他の相続人の遺留分を侵害することがあります。

対策：

- **遺留分に関する民法の特例**（経営承継円滑化法）を使う
- 他の相続人に別の財産を分ける
- 遺言を作る
- 生命保険で代償金を準備する

経営承継円滑化法の特例では、推定相続人全員の合意と、経済産業大臣の確認、家庭裁判所の許可が必要です。手続きに時間がかかるため、早めに着手してください。

## 株価の算定

自社株の評価は、会社の規模と業種によって方法が変わります。

- 類似業種比準方式
- 純資産価額方式
- 両者の併用

**利益、配当、純資産**が評価の要素になります。利益が出ていて内部留保が厚い会社ほど、評価が高くなります。

評価を下げる方法として、役員退職金の支給、不良資産の処分、含み損のある資産の売却などがあります。ただし、実態のない操作は否認されます。

まず現在の評価額を把握してください。試算しないまま「高いらしい」と言っているだけでは、対策のしようがありません。

## M&Aを選ぶ場合の準備

第三者に譲渡する場合、買い手から見て魅力的な状態にしておく必要があります。

| 見られる点 | 準備 |
|---|---|
| 収益性 | 特定の取引先に依存していないか |
| 属人性 | 社長がいなくても回るか |
| 簿外債務 | 未払残業代、社会保険の未加入、係争 |
| 資産の実態 | 不良在庫、回収不能の売掛金 |
| 許認可 | 承継できるか（事業譲渡では再取得が必要な場合あり） |
| 契約関係 | チェンジオブコントロール条項の有無 |

**未払残業代と社会保険の未加入**は、デューデリジェンスで必ず出てきます。譲渡価格の減額要因になるか、そもそも破談になります。

[労働時間の管理](/roumu/36-kyotei-jogen/)と社会保険の加入状況を、事前に整理してください。

## 使える制度

| 制度 | 内容 |
|---|---|
| 事業承継税制（特例措置） | 自社株の贈与税・相続税の納税猶予 |
| 経営承継円滑化法の金融支援 | 承継資金の融資・保証の特例 |
| 遺留分に関する民法の特例 | 生前贈与株式を遺留分の対象から除外等 |
| 事業承継・引継ぎ補助金 | 承継・M&Aに伴う費用の補助 |
| 事業承継・引継ぎ支援センター | 各県に設置。無料で相談可能 |

**まず事業承継・引継ぎ支援センターに行ってください。** 無料で、全体像を整理してもらえます。民間の仲介会社に相談する前に、公的機関で自社の状況を把握するほうが安全です。

[補助金コンサルに頼む前に確認すること](/risk/hojokin-consultant/)と同様、M&A仲介でも手数料の体系を書面で確認してください。
