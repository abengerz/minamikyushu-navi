消費税の納税額は、どの計算方法を選ぶかで変わります。選択肢は次のとおりです。

| 方法 | 対象 | 計算 |
|---|---|---|
| 一般課税 | 全事業者 | 売上税額 − 実際の仕入税額 |
| 簡易課税 | 基準期間の課税売上高5,000万円以下 | 売上税額 − 売上税額 × みなし仕入率 |
| 2割特例 | インボイス登録で課税事業者になった者 | 売上税額 × 20％ |
| 3割特例 | 同上のうち個人事業者 | 売上税額 × 30％ |

2割特例は令和8年9月30日が属する課税期間まで、3割特例は個人事業者の令和9年分・令和10年分の申告までです。詳しくは[インボイス経過措置の記事](/zeimu/invoice-keikasochi-2026/)を参照してください。

## みなし仕入率

簡易課税では、業種に応じたみなし仕入率を使います。

| 事業区分 | みなし仕入率 | 主な業種 |
|---|---|---|
| 第1種 | 90％ | 卸売業（購入した商品をそのまま他の事業者に販売） |
| 第2種 | 80％ | 小売業、飲食料品の譲渡に係る農林漁業 |
| 第3種 | 70％ | 建設業、製造業、飲食料品以外の農林漁業、鉱業、電気・ガス・水道業 |
| 第4種 | 60％ | 飲食店業、第1〜3種と第5〜6種以外 |
| 第5種 | 50％ | 運輸通信業、金融保険業、サービス業（飲食店業を除く） |
| 第6種 | 40％ | 不動産業 |

## 判断の方法

計算はこれだけです。

> 実際の課税仕入率 ＝ 課税仕入れの額 ÷ 課税売上高

この率が**みなし仕入率より低ければ簡易課税が有利**です。

### 例：サービス業（第5種・50％）

年間の課税売上高 3,000万円、課税仕入れ 900万円（30％）の場合。

**一般課税**
- 売上税額：3,000万円 × 10％ = 300万円
- 仕入税額：900万円 × 10％ = 90万円
- 納税額：**210万円**

**簡易課税**
- 売上税額：300万円
- みなし仕入税額：300万円 × 50％ = 150万円
- 納税額：**150万円**

簡易課税のほうが60万円少なくなります。

### 例：建設業（第3種・70％）

年間の課税売上高 5,000万円、外注費・材料費 4,000万円（80％）の場合。

**一般課税**
- 納税額：500万円 − 400万円 = **100万円**

**簡易課税**
- 納税額：500万円 − 350万円 = **150万円**

この場合は一般課税が有利です。外注比率の高い建設業では、簡易課税が不利になることがあります。

## 業種ごとの傾向

| 業種 | 簡易課税が有利になりやすい条件 |
|---|---|
| サービス業 | 人件費中心で仕入れが少ない（人件費は課税仕入れではありません） |
| 士業 | 同上。多くの場合で簡易課税が有利 |
| 飲食店 | 原価率が60％を下回っている場合 |
| 建設業 | 一人親方など、外注が少なく人工中心の場合 |
| 小売業 | 粗利率が20％を超えている場合 |
| 不動産賃貸 | 課税売上が駐車場等に限られる場合 |

:::point
**人件費は課税仕入れではありません。** 給与を払っても仕入税額控除はできません。人件費の比重が高い事業ほど、簡易課税が有利になりやすいのはこのためです。逆に、外注費は課税仕入れになります。同じ作業を社員にやらせるか外注するかで、消費税の計算が変わります。
:::

## 届出の期限と2年縛り

### 原則

適用を受けようとする課税期間の**開始日の前日まで**に「消費税簡易課税制度選択届出書」を提出します。

3月決算の法人が令和9年4月からの期で簡易課税を使いたい場合、令和9年3月31日までに提出します。期が始まってからでは間に合いません。

### 2割特例・3割特例の後は緩和されています

2割特例または3割特例の適用を受けた課税期間の**翌課税期間**については、**その課税期間の申告期限まで**に提出すれば適用できます。

1年分の実績を見てから、簡易課税と一般課税のどちらが有利かを判断して選べます。

:::warn
2割特例の翌課税期間が令和8年9月30日以前に終了する場合は、その課税期間の末日までが期限です。
:::

### 2年間は変更できません

簡易課税を選択すると、原則として**2年間は継続適用**が必要です。

「今年は簡易課税、来年は一般課税」と毎年切り替えることはできません。大きな設備投資を予定している年は、一般課税のほうが有利になる（仕入税額控除が大きくなる）ため、投資計画と合わせて判断してください。

## 設備投資がある年は注意

建物や大型機械を購入すると、その年の課税仕入れが大きくなります。一般課税なら、仕入税額控除が売上税額を上回って**還付**になることもあります。

簡易課税を選択していると、どれだけ設備投資をしても還付は受けられません。

3年以内に大型の設備投資を予定しているなら、簡易課税の選択は慎重に判断してください。[補助金を使った設備投資](/hojokin/list/)を検討している場合も同様です。

## 複数の事業を行っている場合

事業区分が複数にまたがる場合、原則として区分ごとに計算します。区分していない売上は、そのなかで最も低いみなし仕入率が適用されます。

たとえば小売（第2種・80％）と飲食（第4種・60％）を営んでいて、売上を区分していない場合、全体に60％が適用されます。

**レジや売上帳で事業区分ごとに集計できる状態**にしておいてください。区分していないだけで納税額が増えます。

なお、1つの事業区分の課税売上高が全体の75％以上を占める場合、全体にその区分のみなし仕入率を適用できる特例があります。

## 判断の手順

1. 直近2期の課税売上高と課税仕入れの額を出す
2. 実際の課税仕入率を計算する
3. 自社の事業区分のみなし仕入率と比べる
4. 今後2年の設備投資予定を確認する
5. 届出の期限を確認する

2番の「課税仕入れ」には、給与、社会保険料、支払利息、減価償却費は含まれません。損益計算書の費用合計ではないので注意してください。

## 事業区分の判定で迷いやすいもの

実務で判断に迷う例です。

| 事業 | 区分 | 理由 |
|---|---|---|
| 飲食店の店内飲食 | 第4種 | 飲食店業 |
| 飲食店のテイクアウト | 第3種 | 製造した商品の販売として扱われる場合 |
| 建設業の材料持ち | 第3種 | 製造業等 |
| 建設業の手間請け（材料は元請支給） | 第4種 | 加工賃等を対価とする役務の提供 |
| 自動車整備の部品販売 | 第2種または第3種 | 販売形態による |
| 美容室の商品販売 | 第2種 | 小売 |
| 美容室の施術 | 第5種 | サービス業 |
| 不動産の賃貸 | 第6種 | 不動産業 |
| 太陽光の売電 | 第3種 | 電気業 |

:::warn
**建設業の手間請けは第4種です。** 材料を自社で調達する場合は第3種ですが、元請から材料が支給される場合は第4種になります。みなし仕入率が70％と60％で10ポイント違うため、判定を誤ると納税額が変わります。
:::

同じ会社でも、工事の請け方によって区分が変わります。契約内容を確認してください。

## 区分経理の実務

複数の事業区分がある場合、売上を区分して記録します。

**レジで分ける**

小売と飲食を営む店なら、レジの部門設定を分けます。日報で区分別の売上が出る状態にしてください。

**請求書で分ける**

建設業で材料持ちと手間請けが混在する場合、請求書の段階で分けて記載します。

**会計ソフトで補助科目を使う**

売上高の補助科目を「売上（第2種）」「売上（第4種）」のように分けます。

いずれの方法でも、**申告時に区分別の課税売上高を集計できる**状態であることが必要です。

## 75％ルール

事業区分が2つ以上ある場合の特例です。

### 1種類の事業で75％以上を占める場合

その事業のみなし仕入率を、**全体に適用**できます。

例：小売（第2種・80％）が80％、飲食（第4種・60％）が20％の場合。全体に80％を適用できます。区分ごとに計算するより有利です。

### 2種類の事業で75％以上を占める場合（3種類以上ある場合）

そのうち高いほうのみなし仕入率を、残りの事業にも適用できる特例があります。

計算方法が複数あるため、原則計算と特例計算の両方を計算して有利なほうを選びます。会計ソフトが対応していることが多いので、区分さえ正しく入力されていれば自動で判定されます。

## 基準期間と特定期間

簡易課税を使えるのは、**基準期間の課税売上高が5,000万円以下**の場合です。

- 個人事業主の基準期間：前々年
- 法人の基準期間：前々事業年度

当期の売上が5,000万円を超えても、基準期間が5,000万円以下なら簡易課税を使えます。逆に、当期が減収でも基準期間が5,000万円超なら使えません。

:::point
売上が5,000万円前後を行き来する事業者は、2年前の数字で毎年判定が変わります。届出書は提出したままでよく、要件を満たす年だけ簡易課税が適用されます。
:::

## 届出書の種類

| 届出書 | 内容 | 期限 |
|---|---|---|
| 消費税簡易課税制度選択届出書 | 簡易課税を選ぶ | 適用したい課税期間の開始日の前日まで（特例あり） |
| 消費税簡易課税制度選択不適用届出書 | 簡易課税をやめる | 適用をやめたい課税期間の開始日の前日まで |
| 消費税課税事業者選択届出書 | 免税事業者が課税事業者になる | 同上 |
| 消費税課税事業者選択不適用届出書 | 上記をやめる | 同上 |

いずれも**事前提出**が原則です。提出を忘れると、1年待つことになります。

:::warn
簡易課税をやめる場合も、2年間の継続適用期間が経過している必要があります。設備投資の年に一般課税へ戻したくても、2年縛りの途中なら戻れません。
:::

## 災害等があった場合の特例

災害その他やむを得ない事情が生じた場合、届出の期限に関する特例（承認申請）があります。

被災して設備の再取得が必要になり、一般課税のほうが有利になった、といった場面で使えます。税務署への承認申請が必要です。

宮崎・鹿児島は台風・豪雨の被害を受けやすい地域です。該当する場合は、税務署または顧問税理士に相談してください。

## 判断の材料をそろえる

有利不利の判定には、課税仕入れの実額が必要です。損益計算書の費用合計ではありません。

**課税仕入れに含まれないもの**

- 給与・賞与・法定福利費
- 支払利息
- 減価償却費
- 租税公課
- 保険料
- 国内の非課税取引（土地の賃借料など）

人件費の比重が高い事業ほど、簡易課税が有利になりやすいのはこのためです。[外注と社員のどちらにするか](/zeimu/keiri-naisei-gaichu/)は、消費税の観点でも違いが出ます。

月次の試算表で課税仕入れの額を把握できる状態にしておけば、判定は数分で終わります。
