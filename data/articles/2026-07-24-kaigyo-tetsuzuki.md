開業や会社設立の直後は、提出する書類が集中します。**期限を過ぎると取り返しがつかないもの**があるので、最初に整理しておいてください。

とくに青色申告の承認申請は、出し忘れるとその年の節税手段が大きく減ります。

## 個人事業を始めたとき

### 税務署に出すもの

| 書類 | 期限 | 出し忘れると |
|---|---|---|
| 個人事業の開業・廃業等届出書 | 開業から1か月以内 | 罰則はないが、他の手続きで必要になる |
| **所得税の青色申告承認申請書** | 開業から2か月以内（1/1〜1/15開業なら3月15日まで） | **その年は白色申告になる** |
| 青色事業専従者給与に関する届出書 | 上記と同じ | 家族への給与を経費にできない |
| 給与支払事務所等の開設届出書 | 従業員を雇ってから1か月以内 | — |
| 源泉所得税の納期の特例の承認に関する申請書 | 適用を受けたい月の前月まで | 源泉所得税を毎月納付することになる |

:::warn
**青色申告承認申請書がいちばん重要です。** これを出していないと、65万円（または55万円・10万円）の青色申告特別控除、赤字の繰越し、30万円未満の少額減価償却資産の特例、家族への給与の経費算入がすべて使えません。開業届と一緒に出してください。
:::

「納期の特例」は、源泉所得税の納付を年2回（7月と1月）にまとめられる制度です。給与の支給人数が常時10人未満の事業者が使えます。毎月10日の納付をなくせるので、必ず申請してください。

### 県税事務所・市町村に出すもの

- 個人事業税の事業開始等申告書（県税事務所）

宮崎県は各県税・総務事務所、鹿児島県は各地域振興局の県税課が窓口です。

### 年金事務所・労働基準監督署・ハローワーク

従業員を雇う場合に必要です。

| 書類 | 提出先 | 期限 |
|---|---|---|
| 労働保険 保険関係成立届 | 労働基準監督署 | 雇用から10日以内 |
| 労働保険 概算保険料申告書 | 同上 | 雇用から50日以内 |
| 雇用保険 適用事業所設置届 | ハローワーク | 雇用から10日以内 |
| 雇用保険 被保険者資格取得届 | 同上 | 雇用した月の翌月10日まで |

個人事業で常時5人以上（一部の業種を除く）を雇う場合、社会保険（健康保険・厚生年金）の適用事業所になります。

## 法人を設立したとき

### 税務署

| 書類 | 期限 |
|---|---|
| 法人設立届出書 | 設立から2か月以内 |
| **青色申告の承認申請書** | 設立から3か月を経過した日と、最初の事業年度終了の日のうち早いほうの前日まで |
| 給与支払事務所等の開設届出書 | 設立から1か月以内 |
| 源泉所得税の納期の特例の承認に関する申請書 | 適用を受けたい月の前月まで |
| 棚卸資産の評価方法の届出書 | 最初の確定申告の提出期限まで |
| 減価償却資産の償却方法の届出書 | 同上 |

法人の青色申告も、赤字の繰越し（10年）と各種特例の前提になります。必ず出してください。

### 県・市町村

- 法人設立・設置届出書（県税事務所）
- 法人設立・設置届出書（市町村の税務担当課）

税務署とは別に、県と市町村それぞれに出します。忘れやすい項目です。

### 年金事務所

**法人は従業員が社長1人でも社会保険の適用事業所**になります。

| 書類 | 期限 |
|---|---|
| 健康保険・厚生年金保険 新規適用届 | 設立から5日以内 |
| 被保険者資格取得届 | 同上 |
| 被扶養者（異動）届 | 扶養家族がいる場合 |

役員報酬をゼロにする場合は加入できませんが、報酬を払うなら加入が必要です。

## 消費税の届出

開業時に判断が必要なものです。

| 書類 | 場面 |
|---|---|
| 消費税課税事業者選択届出書 | 免税事業者が、あえて課税事業者になる場合 |
| 適格請求書発行事業者の登録申請書 | インボイスを発行する場合 |
| 消費税簡易課税制度選択届出書 | 簡易課税を選ぶ場合 |

設備投資が大きく、支払った消費税のほうが多くなる見込みなら、課税事業者を選択して還付を受けられることがあります。ただし2年間は戻れません。

インボイスの登録をするかどうかは、取引先の構成で判断してください。[簡易課税と一般課税の選び方](/zeimu/kanien-kazei-erabikata/)も参照してください。

## 許認可が要る業種

開業届とは別に、営業許可が必要な業種があります。

| 業種 | 許認可 | 窓口 |
|---|---|---|
| 飲食店 | 食品衛生法の営業許可 | 保健所 |
| 建設業（一定規模以上） | 建設業許可 | 県の土木事務所等 |
| 古物の売買 | 古物商許可 | 警察署（公安委員会） |
| 運送業 | 一般貨物自動車運送事業の許可 | 運輸支局 |
| 理美容 | 開設届 | 保健所 |
| 宿泊 | 旅館業の許可 | 保健所 |
| 産業廃棄物の収集運搬 | 許可 | 県 |

許可が下りるまでに1〜2か月かかるものがあります。**開業日から逆算して動いてください。**

## 銀行口座と決済

- 事業用の口座を分ける（個人事業でも必ず分けてください）
- 事業用のクレジットカードを作る
- 会計ソフトに口座とカードを連携する

口座を分けていないと、記帳のたびに生活費と事業経費を仕分ける作業が発生します。[経理の手間](/zeimu/keiri-naisei-gaichu/)が最初から膨らみます。

連携まで済ませておけば、取引の大半が自動で会計ソフトに入ります。開業時にやっておくのが最も楽です。

## 開業後1年以内に検討するもの

- [小規模企業共済](/zeimu/shoukibo-kigyo-kyosai/)（掛金が全額所得控除。加入は早いほど有利）
- [倒産防止共済](/yushi/tousan-boushi-kyosai/)（継続1年以上が加入要件）
- [就業規則](/roumu/shuugyo-kisoku/)（従業員10人以上で義務。それ未満でも作る価値あり）
- [補助金](/hojokin/list/)（創業枠がある制度もあります）

## 開業前にやっておくとよいこと

[日本政策金融公庫の創業融資](/yushi/kouko-yushi/)を考えているなら、開業の半年〜1年前から自己資金を計画的に積み立ててください。通帳の履歴が審査で見られます。

## 法人と個人のどちらで始めるか

開業前に決めることです。後から法人化（法人成り）もできますが、手間がかかります。

| | 個人事業 | 法人 |
|---|---|---|
| 設立費用 | 0円 | 株式会社で20万円台、合同会社で10万円前後 |
| 税率 | 累進（所得が増えるほど高い） | ほぼ一定 |
| 社会保険 | 原則任意（一部業種を除く） | **強制加入**（社長1人でも） |
| 赤字の繰越し | 3年（青色） | 10年（青色） |
| 決算 | 12月31日固定 | 自由に決められる |
| 信用度 | — | 取引先・金融機関から見て有利なことが多い |
| 経費の範囲 | やや狭い | [社宅](/zeimu/shataku-seido/)、[退職金](/zeimu/yakuin-hoshu-kimekata/)など選択肢が広い |
| 廃業 | 届出のみ | 解散・清算の手続きが必要 |

**判断の目安**

- 所得が継続的に800万円を超えそう → 法人が有利になりやすい
- 取引先が法人との取引を求める → 法人
- 許認可の要件で法人が必要 → 法人
- 社会保険料の負担を避けたい → 個人
- まず小さく始めたい → 個人

社会保険は見落としがちです。法人にすると、社長1人でも健康保険・厚生年金に加入します。役員報酬が月30万円なら、本人負担と会社負担を合わせて月9万円前後かかります。

## 決算期の決め方（法人）

法人は決算期を自由に決められます。次の観点で選んでください。

- **繁忙期を避ける**（決算作業と業務が重なると回りません）
- **在庫が少ない時期にする**（棚卸しが楽になります）
- **資金に余裕がある時期の2か月後に納税が来るようにする**

3月決算にする必要はありません。むしろ税理士事務所が混み合う時期なので、避けたほうが丁寧に見てもらえることがあります。

## 設立時に決めること（法人）

| 項目 | 考え方 |
|---|---|
| 商号 | 同一住所で同一商号は登記できない。類似商号も調査する |
| 本店所在地 | 自宅でも可。ただし賃貸なら契約を確認 |
| 事業目的 | 許認可が必要な事業は文言に注意。将来やる事業も入れておく |
| 資本金 | 1円でも可だが、信用と運転資金の観点で決める |
| 役員構成 | 取締役1名でも可 |
| 事業年度 | 上記のとおり |

**資本金1,000万円以上にすると、設立初年度から消費税の課税事業者**になります。特段の理由がなければ1,000万円未満にしてください。

事業目的は後から変更できますが、登記費用がかかります。将来やる可能性のある事業も、最初に入れておくほうが経済的です。

## 屋号と印鑑

- 個人事業でも屋号は使えます（登記は不要）
- 屋号名義の銀行口座は、開業届の控えがあれば作れることが多い
- 法人は代表者印（実印）、銀行印、角印を作るのが一般的

法人の印鑑は、設立登記の際に必要です。商号が決まったら発注してください。

## 会計ソフトの準備

開業のタイミングで整えるのが、いちばん楽です。

1. クラウド会計ソフトを契約する
2. 事業用の銀行口座を連携する
3. 事業用のクレジットカードを連携する
4. 請求書発行も同じソフトで行う（転記がなくなります）

後から導入すると、それまでの取引を遡って入力することになります。

[バックオフィスのDX](/ai/backoffice-dx/)で触れたとおり、転記をなくすのが目的です。最初からその形で始められるのは、開業時だけの利点です。

## 保険の検討

- 労災保険の特別加入（一人親方、社長）
- 賠償責任保険（業務上の事故に備える）
- 所得補償保険（働けなくなったときの生活費）
- [小規模企業共済](/zeimu/shoukibo-kigyo-kyosai/)（退職金の準備。掛金は全額所得控除）

小規模企業共済は、納付月数が長いほど有利になります。開業時に加入しておくと、将来の受取額が変わります。

## よくある失敗

:::warn
- **青色申告承認申請書を出し忘れる**（その年は白色になります。最も多い失敗です）
- 事業用と生活用の口座を分けていない
- 領収書を保管していない
- 源泉所得税の納期の特例を申請していない（毎月納付になります）
- 許認可が下りる前に営業を始めてしまう
- インボイスの登録を、取引先を確認せずに済ませてしまう
:::

最後の項目については、[簡易課税と一般課税の選び方](/zeimu/kanien-kazei-erabikata/)を参照してください。取引先が一般消費者中心なら、登録の必要性は低くなります。
