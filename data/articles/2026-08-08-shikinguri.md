決算は黒字なのに、手元の資金が足りない。この状態には必ず原因があります。

利益と現金がずれる場所は4つしかありません。順に確認していきます。

## 1. 売掛金が増えている

売上が増えれば利益は増えますが、入金は後です。

月商1,000万円、回収が翌々月末の会社が、月商1,500万円に増えたとします。利益は増えますが、増えた500万円×2か月分＝1,000万円は、入金されるまで手元にありません。

**売上が伸びているときほど資金が足りなくなる**のはこのためです。増収期の黒字倒産はここで起きます。

確認する数字：

> 売上債権回転期間 ＝ 売掛金 ÷ 月商

3か月分の売掛金があるなら、3か月分の資金を立て替え続けている状態です。この数字が前期より伸びていれば、回収が遅くなっています。

## 2. 在庫が増えている

仕入れた時点で現金は出ていきますが、経費になるのは売れたときです。

売れていない在庫は、貸借対照表の資産として残り、損益計算書には出てきません。利益は減らないまま、現金だけが減ります。

確認する数字：

> 棚卸資産回転期間 ＝ 在庫 ÷ 月商

業種によって適正水準は違いますが、前期と比べて伸びていれば、売れない在庫が溜まっています。

## 3. 借入金の元本返済

これがいちばん見落とされます。

**借入金の元本返済は経費になりません**。経費になるのは利息だけです。

月10万円ずつ返済している場合、年間120万円の現金が出ていきますが、損益計算書には利息分しか出てきません。税引後の利益から返済していることになります。

確認する考え方：

> 返済に回せる原資 ＝ 税引後利益 ＋ 減価償却費

この金額が年間の元本返済額を下回っていれば、返済のために資金が減り続けています。借り換えか、返済条件の見直しが必要な状態です。

## 4. 税金と社会保険料

法人税、消費税、社会保険料は、利益が出た後に払います。

特に**消費税**は要注意です。預かった消費税は自社の売上ではありませんが、入金された時点では区別がつきません。使ってしまうと、納付期限に足りなくなります。

年1回の納付だと、1年分をまとめて払うことになります。中間納付の対象でなければ、納税用の資金を別口座に分けておくのが確実です。

## 資金繰り表を作る

上の4つは、損益計算書では見えません。資金繰り表が必要です。

最低限、次の形で3か月先まで作ってください。

| 項目 | 今月 | 翌月 | 翌々月 |
|---|---|---|---|
| 前月繰越 | | | |
| 売上入金 | | | |
| その他入金 | | | |
| **収入計** | | | |
| 仕入・外注払 | | | |
| 人件費 | | | |
| 経費 | | | |
| 借入返済（元本） | | | |
| 税金・社会保険 | | | |
| **支出計** | | | |
| **翌月繰越** | | | |

作るときのコツは、**入金は遅め、支出は早め**に見積もることです。楽観的に作ると、実際に足りなくなったときに気づくのが遅れます。

:::point
Excelで構いません。重要なのは精度より、毎月更新することです。実績と予測のずれを毎月確認していると、3か月後の資金が読めるようになります。
:::

## 足りないと分かったときの順序

1. **入金を早める**：請求の前倒し、前受金、支払サイトの交渉
2. **支出を遅らせる**：仕入先への支払条件の相談
3. **固定費を削る**：[通信費など](/cost/tsushinhi-sakugen/)から着手
4. **借入を検討する**：資金が尽きる2〜3か月前に動く
5. **返済条件を見直す**：リスケジュールの相談

4番のタイミングが重要です。資金が尽きる直前に相談に行くと、審査に通りません。**余裕があるうちに動く**のが原則です。

銀行に相談する際は、資金繰り表が必須の資料になります。[銀行は決算書のどこを見ているか](/yushi/ginko-kessansho/)もあわせて確認してください。

## 資金繰り表の精度を上げる

作り始めると、予測が当たらないことに気づきます。原因はだいたい次の4つです。

### 入金予定が読めていない

請求書の発行月と入金月がずれている取引先があると、予測がずれます。取引先ごとに「締め日・支払日・サイト」を一覧にしてください。

| 取引先 | 締め | 支払 | サイト | 手段 |
|---|---|---|---|---|
| A建設 | 月末 | 翌月末 | 30日 | 振込 |
| B商事 | 20日 | 翌々月10日 | 50日 | 手形 |

手形が残っている取引先は、割引前提なのか満期まで持つのかで資金の入り方が変わります。

### 賞与・決算賞与を入れ忘れる

毎月の人件費だけを入れていると、賞与月に一気に狂います。年間の支給予定を先に入れてください。

### 税金・社会保険の納付月を漏らす

- 法人税・消費税：決算日から2か月以内
- 源泉所得税：翌月10日（納期の特例なら年2回）
- 社会保険料：翌月末
- 労働保険料：年度更新（6月〜7月）、分割納付なら年3回
- 固定資産税：年4回（市町村により時期が異なります）
- 自動車税：5月

固定資産税と労働保険料は年に数回しかないため、見落としやすい項目です。

### 設備投資・大型仕入れが入っていない

「決まったら入れる」ではなく、検討中のものも金額を仮置きしてください。入れておけば、実行できるかどうかが事前に分かります。

## 資金がショートするまでの日数

いまの手元資金で何日もつかを示す指標です。

> 手元流動性（月商比）＝（現金預金 ＋ すぐ換金できる資産）÷ 月商

1.0か月分が最低ライン、1.5〜2.0か月分あれば当面は安心とされます。0.5か月分を切ると、入金が1回遅れただけで支払いが止まります。

南九州のように取引先が地域内に集中している場合、1社の倒産が連鎖することがあります。手元流動性は多めに持っておいたほうが安全です。

## 当座貸越と短期継続融資

資金繰りの波を借入で埋める方法として、当座貸越（極度枠）があります。枠を設定しておけば、必要なときに必要な額だけ借りられます。

証書貸付で毎月元本を返す形と違い、資金繰りの平準化に向いています。ただし枠の設定には相応の信用が必要です。

短期継続融資（手形貸付を期日に書き換えていく形）も、運転資金の調達手段として見直されています。経常的に必要な運転資金を、長期借入の分割返済で賄っている会社は、金融機関に相談してみる価値があります。

> 経常運転資金 ＝ 売掛金 ＋ 在庫 − 買掛金

この金額は、事業を続ける限り必要な資金です。これを10年の分割返済で借りていると、返済のたびに資金が減ります。短期継続融資に切り替えられれば、元本返済の負担が消えます。

## 支払いを止める順序

どうしても払いきれないとき、止める順序があります。

1. **絶対に遅らせてはいけない**：給与、源泉所得税、社会保険料
2. **相談の余地がある**：仕入先への支払い（事前に連絡する）
3. **リスケの対象**：銀行への元本返済

給与の遅配は、従業員の離職に直結します。また源泉所得税と社会保険料は、滞納すると延滞金が高く、差押えにもつながります。

銀行への返済は、**事前に相談すれば**条件変更（リスケジュール）に応じてもらえることがあります。無断で延滞すると信用を失うため、払えないと分かった時点で連絡してください。

:::warn
順序を間違えて、銀行への返済を優先して仕入先への支払いを止めると、材料が入らなくなって事業そのものが止まります。どちらが事業の継続に効くかで判断してください。
:::

## 月次が遅れていると手遅れになります

ここまでの話は、直近の数字が出ていることが前提です。月次が2か月遅れている会社では、資金繰り表の起点になる現在の残高すら正確に把握できません。
