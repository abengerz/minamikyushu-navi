2026年10月、宮崎県の最低賃金は1,085円、鹿児島県は1,090円になります。この引上げに合わせて設備投資をする中小企業向けに、**業務改善助成金**があります。

制度の趣旨は「賃金を上げるなら、同時に生産性も上げてください。その設備投資は国が一部負担します」というものです。

## 最初に押さえること：申請の順序

この助成金でいちばん多い失敗は、順序です。

:::warn
**交付申請は、賃金を引き上げる前に行います。** 先に賃金を引き上げてしまうと、その引上げは助成の対象になりません。「10月に上げたので、11月に申請します」は通りません。
:::

正しい順序はこうです。

1. 引き上げる賃金額と、導入する設備を決める
2. **交付申請**を労働局に出す
3. 交付決定を受ける
4. 設備を導入する（発注・契約も交付決定後）
5. 賃金を引き上げる
6. 実績報告を出す
7. 助成金が支払われる

設備の発注も交付決定の後です。「見積りを取っただけ」は問題ありませんが、発注書を出した時点でアウトになります。

10月24日・25日の発効を待っていると間に合いません。9月中に動き始める必要があります。

## 対象になる設備

生産性の向上に資する設備・機器、およびコンサルティングの導入が対象です。実際に使われている例を挙げます。

| 業種 | 導入例 |
|---|---|
| 飲食業 | POSレジ、自動釣銭機、食器洗浄機、券売機 |
| 小売業 | 在庫管理システム、セルフレジ、発注システム |
| 建設業 | 積算ソフト、工程管理システム、小型建機 |
| 製造業 | 加工機械、検査装置、生産管理システム |
| 介護・医療 | 記録システム、移乗支援機器 |
| 全業種 | 会計ソフト、給与計算システム、RPA、業務用パソコン |

単なるパソコンの買い替えは対象になりにくい一方、「何の作業を、どれだけ削減するか」が計画として書けていれば対象になります。ここが申請書の勝負どころです。

## 申請書で見られるところ

審査で見られるのは、設備の価格の妥当性ではなく、**生産性向上の筋道**です。

書くべきことは3つです。

1. 今、その作業に何時間かかっているか
2. 設備を入れると何時間になるか
3. 浮いた時間で何をするか

「レジ締めに毎日40分かかっている。自動釣銭機を入れると10分になる。年間で約120時間浮く。その時間を接客と仕込みに回す」という粒度まで書けていれば通ります。

逆に「業務効率化を図る」「生産性を向上させる」といった抽象的な記載だけだと、金額が妥当でも落ちます。

:::point
数字は正確でなくて構いません。実測でなくても、根拠のある見積りであれば問題ありません。重要なのは、作業を具体的に特定していることです。
:::

## 最低賃金の引上げと組み合わせる

2026年10月の改定で賃金を上げなければならない会社は、どのみち人件費が増えます。同じタイミングで設備を入れれば、増える人件費の一部を作業削減で相殺できます。

宮崎県で時給1,030円の従業員が5人いる場合、年間の負担増は社会保険料込みで約60万円です。

この60万円を毎年払い続けるのか、一度設備を入れて作業自体を減らすのか。助成金が使えるのは後者だけです。

## よくある不採択の理由

- 賃金を先に引き上げてしまった
- 交付決定前に設備を発注した
- 事業場内最低賃金の引上げ幅が要件を満たしていない
- 引き上げた賃金を、助成期間後に元に戻した
- 賃金台帳と申請書の金額が合っていない

最後の項目は意外に多いところです。申請書に書いた事業場内最低賃金と、実際の賃金台帳の最低額が一致していないケースがあります。パート・アルバイトを含めた全員の時給を確認してください。

## 事業場内最低賃金とは

この助成金の要件で使われる「事業場内最低賃金」は、地域別最低賃金とは別の概念です。

**その事業場で実際に働いている人のうち、いちばん低い時間給**を指します。パート・アルバイトを含めた全員が対象です。

たとえば宮崎県の事業場で、パートの時給が1,030円、正社員の時給換算が1,400円なら、事業場内最低賃金は1,030円です。

助成金では、この最低額を一定額以上引き上げることが条件になります。引上げ額のコースによって、助成率や上限額が変わります。

:::warn
正社員の時給換算を忘れると、事業場内最低賃金を誤って申告することになります。月給制の社員も、[時給に換算して](/tools/saitei-chingin/)いちばん低い人を特定してください。
:::

## 引き上げた賃金は下げられません

助成金を受けた後、引き上げた賃金を元に戻すと返還を求められます。

「今年は助成金のために上げて、来年下げる」はできません。賃金は下方硬直性があるため、いずれにせよ実務上は下げられないのですが、制度上も明確に禁じられています。

引上げ額を決めるときは、**その水準を今後も払い続けられるか**で判断してください。助成率が高いコースを選んで無理に上げると、翌年以降の人件費が重くなります。

## 生産性要件と事業計画

申請書の中心は、導入する設備でどう生産性が上がるかの説明です。

### 書き方の型

```
現状：レジ締めに毎日40分。担当者2名が交代で対応。
     月間で約20時間。
課題：締め作業が終わるまで閉店できず、残業が発生している。
導入：自動釣銭機付きPOSレジ
効果：釣銭の数え合わせが不要になり、1日10分に短縮。
     月間15時間、年間180時間の削減。
     浮いた時間を仕込みと翌日準備に充てる。
```

現状の時間を測っていない場合は、担当者に聞いて概算で構いません。「だいたい40分」でも、数字が入っているだけで説得力が変わります。

### 落ちる書き方

- 「業務効率化を図る」（何の作業がどれだけ減るか不明）
- 「生産性を向上させる」（同上）
- 「老朽化した設備を更新する」（更新は生産性向上ではありません）
- 「売上を増やす」（この助成金の趣旨は生産性向上です）

4番目は特に注意してください。販路開拓が目的なら[小規模事業者持続化補助金](/hojokin/jizokuka-hojokin/)のほうが適しています。

## 対象外になりやすい経費

- パソコン・タブレット・スマートフォン（単体での購入）
- 車両（業務に不可欠であることの説明が必要）
- 土地・建物の取得
- 事務所の家賃、通信費などの経常経費
- 中古品（要件を満たさない場合）

パソコンは「汎用性が高く、目的外使用になりうるもの」として原則対象外です。業務システムとセットで、そのシステムの稼働に必要な端末として申請する形になります。

## 実績報告で必要なもの

1. 賃金引上げを証明する書類（賃金台帳、労働条件通知書、就業規則）
2. 設備の見積書・発注書・納品書・請求書
3. 支払いの証拠（振込明細）
4. 設備の写真（設置状況が分かるもの）
5. 生産性向上の効果に関する報告

1番が重要です。賃金規程や労働条件通知書を改定していないと、引上げを証明できません。時給を上げたら、必ず書面も更新してください。

## 2026年10月の改定と合わせる

宮崎県は10月24日、鹿児島県は10月25日に最低賃金が改定されます。事業場内最低賃金がこれを下回っている会社は、どのみち引き上げなければなりません。

:::point
どうせ上げるなら、同じタイミングで設備を入れて助成金を取る、という順序が合理的です。ただし**交付申請は引上げ前**なので、10月の発効を待っていると間に合いません。
:::

年間の負担増を試算したうえで、設備投資の金額を決めてください。

## 労働局に相談する

この助成金は各都道府県の労働局が窓口です。申請前に相談すると、要件の当てはめについて助言を受けられます。

- 宮崎県：宮崎労働局
- 鹿児島県：鹿児島労働局

コースの選択（引上げ額と対象人数の組み合わせ）で助成額が変わるため、申請書を書く前に一度相談しておくと、後戻りが減ります。
