常時10人以上の労働者がいる事業場では、就業規則の作成と労働基準監督署への届出が義務です。パート・アルバイトも人数に含みます。

ただし、義務かどうかより重要なのは、**トラブルが起きたときに根拠があるか**です。

## 根拠がないと対応できない場面

### 懲戒処分

就業規則に懲戒の種別と事由を定めていなければ、懲戒処分はできません。

無断欠勤を繰り返す、業務命令に従わない、社内で金銭トラブルを起こした。こうした場面で減給や出勤停止を行うには、あらかじめ規則に定めがあることが必要です。

定めがないまま処分すると、無効になるだけでなく、損害賠償を求められることがあります。

### 休職

私傷病で長期間働けなくなった従業員を休職扱いにするには、休職の規定が必要です。

規定がなければ、休職させることも、休職期間満了で退職扱いにすることもできません。「治るまで在籍させ続ける」しかなくなります。

### 退職の手続き

退職の申し出をいつまでに行うか（民法上は2週間前ですが、規則で1か月前と定めるのが一般的）、引き継ぎの義務、貸与物の返還。これらの根拠になります。

### 配置転換・出向

配転命令権の根拠を就業規則に置いていないと、勤務地や職種の変更を命じられません。

### 副業

副業を制限したい場合も、規則に定めが必要です。ただし、労働時間外は本来自由なので、全面禁止は無効とされる可能性が高く、届出制や許可制にするのが一般的です。

## 必ず記載する事項（絶対的必要記載事項）

1. 始業・終業の時刻、休憩時間、休日、休暇、交替制の就業時転換
2. 賃金の決定・計算・支払方法、締切・支払時期、昇給
3. 退職に関する事項（解雇の事由を含む）

3番の「解雇の事由」は必須です。書いていないと、解雇の根拠を示せません。

## 定めるなら記載する事項（相対的必要記載事項）

- 退職手当
- 臨時の賃金（賞与）、最低賃金額
- 食費、作業用品などの負担
- 安全衛生
- 職業訓練
- 災害補償、業務外の傷病扶助
- **表彰・制裁（懲戒）**
- その他、全労働者に適用される事項

制度を設ける場合は必ず書く、という位置づけです。退職金制度を設けるなら規定が必要ですし、設けないなら「退職手当は支給しない」と明記しておくとトラブルを防げます。

## 最低限入れておきたい条項

10人未満の会社で、ひな形から削らずに残すべき条項です。

| 条項 | なぜ必要か |
|---|---|
| 試用期間 | 本採用の可否を判断する根拠 |
| 休職 | 私傷病で働けなくなったときの扱い |
| 懲戒の種別と事由 | 処分の根拠 |
| 解雇事由 | 解雇の根拠 |
| 退職の申出期限 | 突然辞められることを防ぐ |
| 秘密保持・競業避止 | 情報の持ち出しを防ぐ |
| 配転・出向 | 人員配置を変える根拠 |
| 損害賠償 | 故意・重過失による損害への対応 |
| ハラスメントの禁止 | 措置義務への対応 |
| 副業の届出 | 労働時間の通算・競業の管理 |

:::point
ひな形をそのまま使うと、自社にない制度（家族手当、社宅、退職金など）が書かれたままになることがあります。**規則に書いてあれば支払義務が生じます**。実態に合わない条項は必ず削ってください。
:::

## 作成・変更の手続き

1. 案を作る
2. **労働者の過半数代表者の意見を聴く**（同意までは不要）
3. 意見書を添えて労働基準監督署に届け出る
4. **従業員に周知する**

4番が抜けている会社が多くあります。金庫にしまってある就業規則は、効力を争われたときに「周知されていない」として無効とされることがあります。

周知の方法は、常時各作業場の見やすい場所に掲示する、書面を交付する、社内のネットワークで閲覧できるようにする、のいずれかです。

## 不利益変更

従業員に不利な内容へ変更する場合、原則として**個々の労働者の同意**が必要です。

同意なく変更する場合は、変更後の内容が**合理的**であり、かつ**周知**されていることが必要です。合理性は次の要素で判断されます。

- 労働者が受ける不利益の程度
- 変更の必要性
- 変更後の内容の相当性
- 労働組合等との交渉の状況

賃金や退職金など重要な労働条件の不利益変更には、**高度の必要性に基づいた合理性**が求められます。

:::warn
「就業規則を変えたので明日から手当を廃止します」は通りません。廃止の必要性、代償措置、経過措置、説明の経緯を残してください。
:::

## 別規程に分ける

就業規則本体と別に、次を分けて作るのが一般的です。

- 賃金規程
- 退職金規程
- 育児・介護休業規程
- 旅費規程
- 安全衛生管理規程
- ハラスメント防止規程

分けておくと、改定のたびに本体を触らずに済みます。ただし**別規程も就業規則の一部**なので、作成・変更には同じ手続きが必要です。

旅費規程については[出張手当の設計](/zeimu/yakuin-hoshu-kimekata/)にも関係します。適正な範囲であれば、実費精算より有利になる場面があります。

## 助成金の前提になります

雇用関係の助成金の多くは、就業規則の整備を要件にしています。

- キャリアアップ助成金（正社員化コース）：転換制度の規定が必要
- 両立支援等助成金：育児・介護休業規程の整備が必要
- 人材開発支援助成金：教育訓練に関する規定が必要

助成金を使いたいと思ったときに規則がないと、その時点から整備することになり、間に合わないことがあります。

## 見直す時期

法改正があるたびに確認が必要です。近年だけでも、有給の取得義務、同一労働同一賃金、ハラスメント措置義務、育児介護休業法の改正が続いています。

最低でも2〜3年に一度は見直してください。10年前の規則をそのまま使っている会社は、法改正に対応できていない可能性があります。

## パート・アルバイト用の規則

正社員向けの就業規則しかない会社では、パート・アルバイトにもその規則が適用されると解される可能性があります。

賞与、退職金、各種手当の規定が正社員向けのまま適用されると、支給義務が生じかねません。

対応は2つです。

1. **パートタイム労働者就業規則**を別に作る
2. 正社員の規則に「パートタイム労働者には適用しない。別に定める」と明記する

どちらの場合も、別規程を作らないと、パート・アルバイトの労働条件の根拠がなくなります。

## 同一労働同一賃金

パートタイム・有期雇用労働法により、正社員と非正規社員の間の**不合理な待遇差**が禁止されています。

判断の要素：

1. 職務の内容（業務の内容と責任の程度）
2. 職務の内容・配置の変更の範囲（異動、転勤、昇進の有無）
3. その他の事情

これらが同じなら同じ待遇に、違うなら違いに応じた待遇にする必要があります。

:::warn
特に問題になりやすいのが、**通勤手当、食事手当、慶弔休暇、健康診断**です。これらは職務内容と関連が薄いため、正社員にだけ支給する合理的な理由を説明しにくい項目です。
:::

また、パート・有期雇用労働者から待遇差の内容と理由について説明を求められた場合、**説明する義務**があります。説明できる状態にしておいてください。

## 記載してはいけないこと

法令に反する条項は無効です。

- 法定を下回る年次有給休暇
- 減給の制裁で法定の上限を超えるもの
- 労働契約の不履行に対する違約金・損害賠償額の予定
- 女性であることを理由とする差別的取扱い
- 退職後の競業避止義務で、期間・範囲・代償措置が不相当に広いもの

3番目は注意が必要です。「研修費用を負担した従業員が1年以内に退職した場合、全額を返還させる」といった条項は、内容によって労働基準法第16条違反になります。

貸付金として金銭消費貸借契約を別途結び、一定期間勤務したら返済を免除する形であれば有効とされる場合がありますが、実質的に退職の自由を制限していると判断されれば無効です。

## 周知の方法

法令で認められている周知方法は3つです。

1. 常時各作業場の見やすい場所へ掲示し、または備え付ける
2. 書面を交付する
3. 電子的なデータで記録し、各作業場に労働者が常時確認できる機器を設置する

:::point
3番を使う場合、「社内の共有フォルダに置いてある」だけでは不十分なことがあります。**全員がアクセスできる端末があり、その場所を知らされている**必要があります。現場に出ている従業員がパソコンを触らない職場では、書面の交付のほうが確実です。
:::

## 作るときの順序

1. 現在の実態を書き出す（労働時間、休日、手当、休暇）
2. 法令の最低基準を満たしているか確認する
3. ひな形をベースに、実態に合わせて修正する
4. 実態にない制度を削る
5. 将来的に必要な条項（休職、懲戒、解雇）を入れる
6. 過半数代表者の意見を聴く
7. 届け出る
8. 周知する

1番が起点です。実態を把握せずにひな形を届け出ると、規則と実態が食い違い、かえってリスクになります。

## 助成金と就業規則

雇用関係の助成金の多くは、就業規則の整備が前提です。

| 助成金 | 必要な規定 |
|---|---|
| キャリアアップ助成金（正社員化コース） | 正社員転換制度 |
| 両立支援等助成金 | 育児・介護休業規程 |
| 人材開発支援助成金 | 教育訓練に関する規定 |
| 働き方改革推進支援助成金 | 各コースに応じた制度 |

規定を新設・改定することが支給要件になっている助成金もあります。この場合、**改定前の規則と改定後の規則の両方**が必要になるため、改定前の版も保存しておいてください。

[補助金・助成金の一覧](/hojokin/list/)で現在募集中の制度を確認できます。

## 相談先

作成・改定は、社会保険労務士に依頼するのが一般的です。自社で作る場合も、届出の前に労働基準監督署で相談できます。

厚生労働省が「モデル就業規則」を公開しています。ただし、そのまま使うと自社にない制度が入ったままになるため、必ず実態に合わせて修正してください。

[問題社員への対応](/risk/mondai-shain/)で触れたとおり、トラブルが起きてから規則を作っても間に合いません。平時のうちに整えてください。
