法人保険の相談で多いのが「節税になると言われて入ったが、よく分からないまま払い続けている」というものです。

見直し自体は必要ですが、**解約から入ると失敗します**。順序があります。

## 1. 何のために入ったかを確認する

契約ごとに、加入目的を整理します。目的は大きく4つです。

| 目的 | 必要な保障 |
|---|---|
| 経営者の死亡・就業不能への備え | 当面の運転資金、借入金の返済原資 |
| 従業員の福利厚生 | 弔慰金、見舞金 |
| 役員退職金の準備 | 退職時期に合わせた解約返戻金 |
| 事業承継・相続の納税資金 | 自社株の評価に応じた金額 |

目的が思い出せない契約は、担当者に設計書を出してもらってください。加入時の提案書があれば、何を想定していたかが分かります。

## 2. 保障が必要かを確認する

目的が整理できたら、今もその保障が必要かを見ます。

**経営者の死亡保障**

借入金の残高、従業員の給与の数か月分、取引先への支払い。これらを合計した額が目安です。

借入金が減っていれば、必要な保障額も減っています。加入時から10年経っていれば、状況は変わっているはずです。

**役員退職金の準備**

[役員退職金](/zeimu/yakuin-hoshu-kimekata/)の適正額を試算し、解約返戻金がその時期にピークを迎えるかを確認します。

退職予定が10年後なのに、返戻率のピークが3年後だと、設計が合っていません。

## 3. 解約返戻金の扱いを確認する

ここが重要です。

解約すると**解約返戻金が益金になります**。資産計上している部分との差額が利益として計上されるため、その期の税負担が増えます。

:::warn
「節税のために入った保険を解約したら、解約年に多額の税金が発生した」というのが、最も多い失敗です。解約する年に、同額の損失や費用が出る予定があるかを確認してください。
:::

組み合わせる先の例：

- 役員退職金の支給
- 大規模な修繕・設備投資
- 赤字の期

[倒産防止共済](/yushi/tousan-boushi-kyosai/)と同じ構造です。出口を決めてから入るのが原則で、出口を決めずに入った場合は、出口を作ってから解約します。

## 4. 解約以外の選択肢

解約が唯一の手段ではありません。

### 払済保険に変更する

以後の保険料の払込みを止め、その時点の解約返戻金をもとに保障額を減らした保険に変更します。

- 保険料の支払いが止まる
- 保障は減るが継続する
- 解約返戻金は据え置かれる（契約による）

変更時に経理処理が必要になる場合があります（資産計上額と解約返戻金相当額の差額の処理）。

### 減額する

保険金額の一部を減らし、その分の解約返戻金を受け取ります。全部解約するより、益金の計上を抑えられます。

### 契約者貸付を使う

解約せずに、解約返戻金の一定範囲内で借りられます。利息はかかりますが、資金が必要な場面での一時的な手段になります。

### 名義変更する

経営者が退職する際、退職金の一部として契約を個人に移す方法があります。ただし、この取扱いは税制改正で厳格化されているため、現行のルールを必ず確認してください。

## 保険料の経理処理

保険の種類と返戻率によって、損金算入できる割合が変わります。

法人が支払う定期保険等の保険料は、**最高解約返戻率**に応じて資産計上する割合が定められています。返戻率が高いほど、資産計上する割合が大きくなり、損金になる部分が減ります。

| 最高解約返戻率 | 取扱いの概要 |
|---|---|
| 50％以下 | 全額損金 |
| 50％超70％以下 | 一定期間、一定割合を資産計上 |
| 70％超85％以下 | 同上（資産計上割合が高い） |
| 85％超 | さらに厳しい取扱い |

「全額損金で貯まる保険」は、現在のルールでは成立しません。古い契約は当時のルールが適用されるため、契約時期によって処理が異なります。

## 見直しの手順

1. 契約の一覧を作る（保険会社、種類、保険金額、保険料、加入時期、返戻率のピーク）
2. 加入目的を契約ごとに整理する
3. 現在必要な保障額を計算する
4. 過不足を確認する
5. 解約返戻金の額と、解約した場合の課税額を試算する
6. 出口（組み合わせる損失・費用）の有無を確認する
7. 解約・減額・払済のいずれかを選ぶ

1番の一覧を作るだけで、状況の大半が見えます。複数の保険会社・複数の担当者から加入していると、全体像を誰も把握していないことがよくあります。

## 従業員向けの保障

経営者の保険とは別に、従業員の福利厚生としての保険があります。

- 総合福祉団体定期保険（従業員の死亡保障）
- 業務災害総合保険（労災の上乗せ）
- 団体長期障害所得補償保険

弔慰金・見舞金の規程を作ったうえで加入すると、支給の根拠が明確になります。規程がないまま支給すると、金額の妥当性が問題になることがあります。

## ほかの固定費とあわせて

保険料は、契約したまま見直されない典型的な固定費です。[通信費の見直し](/cost/tsushinhi-sakugen/)と同じ方法で、年に一度、全部の契約を並べる日を作ってください。

ただし保険は、削ることが目的ではありません。必要な保障を必要な額だけ持つ、という状態に近づけるのが見直しです。

## 契約一覧の作り方

見直しの起点になるので、必ず作ってください。保険証券と直近の契約内容のお知らせを集めます。

| 項目 | 確認する場所 |
|---|---|
| 保険会社・証券番号 | 保険証券 |
| 契約者・被保険者・受取人 | 保険証券 |
| 保険の種類 | 保険証券（定期、終身、養老、医療など） |
| 保険金額 | 保険証券 |
| 年間保険料 | 保険証券、通帳 |
| 契約日・保険期間 | 保険証券 |
| 解約返戻金の推移 | 設計書、または保険会社に照会 |
| 返戻率のピーク時期 | 同上 |
| 経理処理（資産計上額） | 総勘定元帳 |

**受取人の確認**は必ず行ってください。法人契約なのに受取人が個人になっている、離婚した配偶者が受取人のまま、といったケースがあります。

## 名義と受取人の組み合わせ

| 契約者 | 被保険者 | 受取人 | 主な用途 |
|---|---|---|---|
| 法人 | 経営者 | 法人 | 事業保障、役員退職金の原資 |
| 法人 | 従業員 | 法人 | 弔慰金の原資 |
| 法人 | 従業員 | 遺族 | 福利厚生（総合福祉団体定期など） |
| 個人 | 経営者 | 家族 | 個人の相続・生活保障 |

受取人が法人の場合、受け取った保険金は益金になります。同時に死亡退職金を支給することで、損金と相殺する設計が一般的です。

:::warn
従業員を被保険者とする保険で受取人を法人にする場合、**本人の同意**が必要です（保険法第38条）。同意がないと契約が無効になります。加入時の同意書が残っているか確認してください。
:::

## 掛け捨てか、貯蓄性か

| | 掛け捨て（定期保険など） | 貯蓄性（終身・養老など） |
|---|---|---|
| 保険料 | 安い | 高い |
| 解約返戻金 | ない、または少ない | ある |
| 損金算入 | 全額または多くが損金 | 資産計上の割合が大きい |
| 向いている場面 | 保障だけがほしい | 退職金の準備を兼ねたい |

保障だけを確保したいなら、掛け捨てのほうが保険料は安く済みます。同じ保険料で保障額を大きくできます。

「貯まるから」という理由で貯蓄性の保険を選ぶと、資金が固定されます。運用として見た場合、[小規模企業共済](/zeimu/shoukibo-kigyo-kyosai/)やiDeCoのほうが税制上の効率が高い場合があります。

## 会社の状況が変われば必要額も変わります

見直しのきっかけになる出来事です。

- 借入金が大きく減った／増えた
- 従業員数が変わった
- 後継者が決まった
- 経営者の年齢が上がった
- 事業を譲渡・縮小した
- 自社株の評価が変わった

特に最後の項目は、[事業承継](/yushi/ginko-kessansho/)を考える段階で影響します。自社株の評価額が上がると、相続時の納税資金が必要になります。

## 保険金が支払われないことがあります

見直しの際、次の点も確認してください。

- **告知義務違反**：加入時に健康状態を正しく告知していないと、支払われないことがあります
- **免責事由**：契約から一定期間内の自殺、故意による事故など
- **保険料の未払い**：口座残高不足で引き落とされず、失効していることがあります

3番目は実際に起きます。年払いの契約で、引落口座を変更したまま保険会社に連絡していない、というケースです。年に一度、引落の実績を通帳で確認してください。

## 相談先

保険の見直しを、加入している保険会社の担当者だけに相談すると、別の保険への切り替えを勧められることがあります。

- 顧問の税理士（経理処理と税務上の影響）
- 複数社を扱う代理店
- よろず支援拠点

の意見も聞いてください。

:::point
**転換（下取り）には注意してください。** 既存の契約を解約して新しい契約に充当する方法ですが、これまで積み上げた解約返戻金が新契約の保険料に消えることがあります。転換を勧められたら、転換せずに新規加入した場合と比較してください。
:::

## 見直しのタイミング

決算のタイミングに合わせるのが合理的です。

- 決算の3〜4か月前に契約一覧を作る
- 着地見込みと合わせて、解約・減額の影響を試算する
- 必要なら決算期中に実行する

[決算直前の対策](/zeimu/kessan-setsuzei/)と同じで、決算が終わってからでは手が打てません。
