ものづくり補助金（ものづくり・商業・サービス生産性向上促進補助金）は、設備投資を伴う取組を支援する制度です。補助額が大きいため関心を持たれますが、**採択のハードルは高い**制度です。

:::point
補助上限額、補助率、公募締切は回ごとに変わります。この記事では審査の考え方を扱います。現在の金額と締切は[補助金の一覧](/hojokin/list/)と公募要領で確認してください。
:::

## 更新投資は対象外です

いちばん多い誤解です。

- 古くなった機械を新しくする → **対象外**
- 同じ製品の生産能力を増やす → **対象外**
- 壊れた設備を買い替える → **対象外**

この制度が求めているのは、**革新性**です。次のいずれかであることを示す必要があります。

1. 新製品・新サービスの開発
2. 新しい生産方式・提供方式の導入
3. 既存製品の高付加価値化

「今までできなかったことが、この設備でできるようになる」という構造です。

## 革新性をどう示すか

「日本初」「業界初」である必要はありません。**自社にとって新しく、かつ地域や同業他社の中で一般的でない**ことを示せば足ります。

### 書き方の例（建設業）

> 現在、当社では鉄筋の加工を外注しており、1件あたり平均5日のリードタイムが発生している。
> 鉄筋自動加工機を導入することで社内加工が可能になり、リードタイムを1日に短縮できる。
> 宮崎県内でこの規模の自動加工機を保有する事業者は○社にとどまり、
> 短納期対応を求める元請からの受注機会を新たに獲得できる。

- 現状の制約が具体的
- 設備によって何が変わるかが明確
- 地域内での位置づけに触れている
- 新しい受注につながる筋道がある

### 通らない書き方

> 老朽化した設備を最新機種に更新し、生産性を向上させる。

何が新しくなるのか、何ができるようになるのかが書かれていません。

## 審査項目

公募要領に審査項目が明記されています。おおむね次の観点です。

### 技術面

- 新製品・新サービスの革新性
- 課題や目標が明確か
- 課題の解決方法が明確で優位性があるか
- 技術的な実現可能性があるか

### 事業化面

- 実施体制と財務状況から、事業を遂行できるか
- 市場ニーズを把握しているか
- 価格的・性能的な優位性があるか
- 事業化までのスケジュールが妥当か
- 費用対効果が高いか

### 政策面

- 地域の経済成長を牽引する事業か
- 経済社会にインパクトをもたらすか
- 先端的なデジタル技術の活用があるか

政策面は、地域の雇用や取引先への波及を書ける会社が有利です。南九州の事業者であれば、地域の一次産業や観光との関連を示せる場合があります。

## 付加価値額の目標

事業計画では、付加価値額の年平均成長率を一定以上とする目標を設定します。

> 付加価値額 ＝ 営業利益 ＋ 人件費 ＋ 減価償却費

この式は覚えておいてください。営業利益だけでなく、人件費と減価償却費を含みます。**設備投資をして減価償却費が増えれば、付加価値額も増えます**。

また、給与支給総額の増加や、事業場内最低賃金の水準に関する要件が設定されることがあります。[最低賃金の引上げ](/roumu/saitei-chingin-2026/)と整合するかを確認してください。

## 事前に必要な準備

1. **gBizIDプライム**の取得（2週間程度）
2. **電子申請システム**への登録
3. 認定経営革新等支援機関への相談（要件による）
4. 設備の見積り（相見積りが必要な場合あり）
5. 直近2期分の決算書

1番は[IT導入補助金](/hojokin/it-dounyu-hojokin/)でも必要です。補助金を使う可能性があるなら、先に取っておいてください。

## 採択された後が本番です

ものづくり補助金は、採択後の事務作業が重い制度です。

- 交付申請（採択＝交付決定ではありません）
- 発注・契約（交付決定後）
- 中間検査がある場合の対応
- 実績報告（証拠書類の量が多い）
- 事業化状況報告（5年間）

特に実績報告では、見積書・発注書・契約書・納品書・請求書・振込明細・現物の写真がすべて揃っている必要があります。1つ欠けると、その経費が対象外になります。

:::warn
**現金払いは認められません。** 必ず銀行振込にし、明細を保存してください。また、交付決定前の発注・契約は対象外です。
:::

## 収益納付

補助事業によって収益が生じた場合、補助金額を上限に返納を求められることがあります（収益納付）。

制度によって取扱いが異なるため、公募要領で確認してください。「補助金をもらって儲かったら一部返す」という仕組みです。

## ほかの制度と比べる

| やりたいこと | 適した制度 |
|---|---|
| 新製品・新工法の開発、革新的な設備 | ものづくり補助金 |
| 人手不足への対応（汎用的な省力化設備） | 省力化投資補助金 |
| 販路開拓（チラシ・HP・展示会） | [小規模事業者持続化補助金](/hojokin/jizokuka-hojokin/) |
| 業務システムの導入 | [IT導入補助金](/hojokin/it-dounyu-hojokin/) |
| 賃上げとセットの生産性向上 | [業務改善助成金](/hojokin/gyomu-kaizen-joseikin-2026/) |

「設備を買いたい」だけであれば、ものづくり補助金より省力化投資補助金のほうが適している場合があります。カタログに掲載された製品から選ぶ形式のため、革新性の証明が不要だからです。

自社の取組がどれに当たるか分からない場合は、商工会議所・商工会、よろず支援拠点で相談してください。

## 事業計画書の構成

様式は公募回によって変わりますが、書く内容の骨格は同じです。

### 1. 補助事業の具体的な取組内容

**現状の課題 → 解決方法 → 導入する設備 → 何が変わるか**の順で書きます。

現状の課題は、数字で書いてください。

> 現在、鉄筋加工を外注しており、発注から納品まで平均5日。
> 年間の外注費は1,800万円。加工待ちにより、
> 年間12件の短納期案件を辞退している。

「効率が悪い」ではなく、日数・金額・件数で書きます。

### 2. 将来の展望（事業化に向けて）

市場規模、想定顧客、競合、価格設定、販売方法を書きます。

**根拠となるデータ**を添えてください。宮崎・鹿児島の事業者なら次が使えます。

- 県の建設工事受注動態統計
- 市町村の人口・世帯数の推移
- 業界団体が公表する統計
- 自社の受注実績（辞退した案件の数など）

自社データがいちばん強い材料です。「過去3年で○件の引き合いを設備不足で断った」という事実は、他社が書けません。

### 3. 会社全体の事業計画

付加価値額、給与支給総額、事業場内最低賃金の推移を計画します。

> 付加価値額 ＝ 営業利益 ＋ 人件費 ＋ 減価償却費

設備投資をすれば減価償却費が増えるため、付加価値額も増えます。ただし、それだけで目標を満たす計画は評価されません。営業利益の増加を伴う計画にしてください。

## 賃上げ要件

近年の公募では、給与支給総額の増加率や、事業場内最低賃金の水準に関する要件が設定されています。

**要件を満たせなかった場合、補助金の返還を求められることがあります。** 計画段階で、実現可能な水準かを検討してください。

2026年10月からは[最低賃金が上がります](/roumu/saitei-chingin-2026/)。宮崎県1,085円、鹿児島県1,090円です。事業場内最低賃金の要件と整合するかを確認してください。

## 補助対象になる経費

制度・枠によって異なりますが、一般的には次の区分があります。

| 区分 | 内容 |
|---|---|
| 機械装置・システム構築費 | 設備の購入、システムの開発 |
| 技術導入費 | 知的財産権等の導入 |
| 専門家経費 | 外部専門家への依頼 |
| 運搬費 | 設備の運搬 |
| クラウドサービス利用費 | クラウドの利用料 |
| 原材料費 | 試作品の開発に必要な材料 |
| 外注費 | 加工や試験の外注 |
| 知的財産権等関連経費 | 特許出願等 |

**機械装置・システム構築費が必須**とされていることが多く、この区分に一定額以上の計上が求められます。

対象外になりやすいもの：

- 汎用的なパソコン・タブレット・スマートフォン
- 車両（用途の説明が必要）
- 建物の建設・不動産の取得
- 従業員の人件費
- 補助金申請の支援に対する報酬

## 加点項目

公募回によりますが、次のような取組が加点されることがあります。

- 経営革新計画の承認
- 事業継続力強化計画（BCP）の認定
- パートナーシップ構築宣言
- 賃上げに関する上乗せの表明
- 事業場内最低賃金が一定水準以上

認定や承認には時間がかかります。公募が始まってから動くと間に合わないため、補助金を使う可能性があるなら先に取得しておいてください。

## 採択後のスケジュール

| 段階 | 目安の期間 |
|---|---|
| 採択発表 | 締切から2〜3か月 |
| 交付申請 | 採択後すぐ |
| 交付決定 | 交付申請から1か月程度 |
| 発注・製作・納品 | 設備による（半年以上かかることも） |
| 実績報告 | 事業完了後30日以内など |
| 補助金の入金 | 実績報告の確定後1〜2か月 |

**申請から入金まで1年以上かかることがあります。** その間の資金は自己資金または借入で賄う必要があります。

つなぎ資金として、[制度融資](/yushi/seido-yushi/)や[日本政策金融公庫](/yushi/kouko-yushi/)の融資を使う会社もあります。補助金の交付決定通知書があれば、融資の審査で材料になります。

## 相談先

- 認定経営革新等支援機関（税理士、中小企業診断士、金融機関など）
- 商工会議所・商工会
- よろず支援拠点
- 各県の産業振興機構

[補助金コンサルに頼む前に確認すること](/risk/hojokin-consultant/)もあわせて読んでください。着手金を先に求める業者には注意が必要です。
