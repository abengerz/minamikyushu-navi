# みなみ九州 経営ナビ

**公開URL**: https://abengerz.github.io/minamikyushu-navi/
**リポジトリ**: https://github.com/abengerz/minamikyushu-navi （public）

宮崎県・鹿児島県の中小企業・個人事業主向けの情報サイト。
`miyazaki-jigyosya.com`（南九州ビジネス支援ナビ）と同じ土俵で、SEO で上を取りにいく。
流入の受け皿は **AI導入支援 / 補助金申請支援 / 経理BPO** の3サービス。

- **構成**: Python 標準ライブラリのみの静的サイトジェネレータ（Node 不使用）
- **公開想定**: GitHub Pages + GitHub Actions
- **Python**: 3.9 で動く（f-string 式の中にバックスラッシュを書けない点に注意）

## 使い方

```
python3 build.py              # site/ に生成
python3 fetch.py --dry-run    # 一次ソースから数字を取り直す（書き込まない）
python3 fetch.py              # 差分があれば data/prefs.json を更新
```

GitHub Pages のプロジェクトページに置く場合（本番はこの設定）:

```
MKN_BASE=/minamikyushu-navi MKN_BASE_URL=https://abengerz.github.io python3 build.py
```

本番の値は GitHub のリポジトリ変数（Settings → Secrets and variables → Actions → Variables）に
`MKN_BASE` / `MKN_BASE_URL` として入れてある。`.github/workflows/deploy.yml` が
main への push と毎日 JST 6:00 に走り、`fetch.py` で一次ソースを取り直してから公開する。

`MKN_BASE_URL` は**オリジンだけ**。パスは `MKN_BASE` に書く。

## 構成

```
lib.py         Markdownレンダラ・レイアウト・構造化データ
build.py       ページ生成（ツールの実装もここ）
fetch.py       最低賃金・協会けんぽ料率を一次ソースから再取得
make_map.py    市町村の境界データからトップの地図SVGを生成（生成物はコミット済み。通常は実行不要）
data/
  site.json          サイト名・運営者・監修者・サービス定義
  prefs.json         宮崎・鹿児島の最低賃金／保険料率／特定最賃
  municipalities.json 69市町村（ローマ字スラッグ付き）
  subsidies.json     県単独の補助金（kyushu-hojokin の巡回結果から抽出）
  jgrants.json       jGrants の制度（宮崎・鹿児島・全国が対象のもの）
  muni_map.json      トップの市町村地図（SVGパス）
  articles/*.md      記事（JSONフロントマター＋Markdown）
assets/        CSS / JS（生成時に site/assets へコピー）
site/          生成物
```

## 記事の書き方

`data/articles/YYYY-MM-DD-slug.md` に置く。ヘッダは JSON。

```
---
{
 "title": "...", "slug": "...", "category": "roumu",
 "date": "2026-09-28", "updated": "2026-09-28",
 "description": "...",
 "service": "hojokin",
 "sources": [{"name": "...", "url": "..."}],
 "faq": [{"q": "...", "a": "..."}]
}
---
本文（Markdown）
```

- `category` は `data/site.json` の categories にある slug
- `service` を書くと記事末の CTA がそのサービスに絞られる
- `faq` を書くと FAQPage 構造化データが出る（競合は未対応）
- 本文中の `{{tool:saitei-chingin}}` で計算ツールを、`{{cta:ai}}` で導線を埋め込める

対応している Markdown は `##`〜`####`、箇条書き、番号付き、表、引用、`:::note` / `:::warn` / `:::point`、
`**強調**`、`[リンク](/内部パス)`、`` `コード` ``。内部リンクは `/` 始まりで書くと `MKN_BASE` が付く。

## 運営者・執筆体制の設定

`data/site.json` の3つのブロックで決まる。

| ブロック | 役割 | 現状 |
|---|---|---|
| `org` | 運営法人。Organization schema と `/about/` に出る | **設定済み**（株式会社アベンジャーズ） |
| `author` | 書いている人。Article.author に入る | **設定済み**（編集部／責任者 宮國 久） |
| `supervisor` | 監修者（税理士）。Article.reviewedBy に入る | **未設定**（`enabled: false`） |

監修者が未設定でも匿名運営にはならないよう、`author` を分けている。
`supervisor.enabled` を `true` にして氏名・登録番号・所属事務所を入れると、
記事末に監修欄が追加され、Person schema と `reviewedBy` が出力される。
`/about/` の「監修体制について」の文面も自動で切り替わる。

税理士の監修がない間は、`/policy/` と `/contact/` に
「当社は税理士法人ではなく、個別の税務相談は受けない」旨を明記している。
記事は一般的な制度の説明にとどめること。

## 公開前に必ずやること

1. **住所と電話番号を `org.offices` / `org.tel` に入れる**（現状は県・市までしか入っていない）。
   空の項目は出力されない作りなので表示は崩れないが、運営者情報としては弱い。
2. ドメインを決めて `MKN_BASE_URL` に設定する。**宮崎を含む名前にしないこと**（鹿児島のページが弱くなる。
   競合が `miyazaki-jigyosya.com` で自分を縛っているのと同じ轍を踏まない）。
3. Search Console と解析を設定する。
4. 監修者が決まったら `supervisor` を埋めて `enabled: true` にする。

## 積み残し

- **市町村ページ（69枚）は未生成**。生成自体はできるが、市町村ごとに固有の中身が無い状態で
  69枚出すと doorway page と判定される。当面はトップの地図とパネルで受けている。
  `kyushu-hojokin/municipal.py` が宮崎・鹿児島の市町村サイトをほとんど拾えていない
  （現状38件、すべて県レベル）ので、まず巡回を直す必要がある。データが揃えば地図の
  クリック先を個別ページに差し替えられる。
- 記事数。競合170本に対して40本。厚みはほぼ追いついた（平均3,202字 対 3,797字）ので、
  残るのは本数。カテゴリごとの未着手キーワードを埋めていく。
- OG画像の生成。
- GitHub Actions のワークフロー（`fetch.py` を日次、`build.py` → Pages）。

## デザインの方針

読み手は会計・税務の専門家ではない。この前提を全体に効かせている。

- **明朝体をやめてゴシックに統一**。角丸と余白で圧を下げる。士業サイトの硬さを避ける
- **トップの入口は専門用語ではなく困りごと**。「従業員の給料、いくらまで上げないといけない？」
  のような実際に口にする言葉から記事へ入る（`build.py` の `ASKS`）
- **期限のカウントダウン**を最上部に置く（`TODOS`）。日付が過ぎた項目は自動で消える
- **カテゴリ名も平易に**。「労務」→「給与と社会保険」、「融資」→「資金繰りと銀行」
- アイコンはインラインSVG（`ICONS`）。外部ライブラリは使わない
- 配色は青(#2457e6)＋橙(#ff6a2b)。ダークモード対応

## トップの市町村地図

`make_map.py` が国土数値情報の行政区域データから、宮崎26＋鹿児島43の計69市町村のSVGパスを生成する。

- 奄美群島・トカラ列島は本土から遠いので、別枠（右側の小パネル）に分けて描いている。
  十島村は口之島が北緯30度をわずかに超えるが、本土枠に入れると地図全体が南へ1度以上
  伸びて本土が小さくなるため、`ISLAND_FORCE` で島嶼側に固定している。
- 離島は図形が小さくクリックしにくいため、地図の下に69件の市町村名ボタンを併置している。
  地名がテキストでページに載るので、地名検索にも効く。
- クリックすると右のパネルにその市町村の情報（県の最低賃金・保険料率・県の独自制度件数・
  団体コード・自治体公式サイト）が出る。個別ページを69枚作っていないのは上記のとおり。

## データの出典

- 厚生労働省「地域別最低賃金の全国一覧」
- 宮崎労働局「宮崎県の最低賃金」／鹿児島労働局「鹿児島県の最低賃金について」
- 全国健康保険協会「令和8年度の協会けんぽの保険料率」
- デジタル庁 jGrants 公開API（`kyushu-hojokin` 経由）
- 国土交通省 国土数値情報（行政区域データ）／スマートニュース メディア研究所が軽量化したものを利用。
  商用可・加工者のクレジットは不要だが、**国土交通省のクレジット表示が必要**なので地図の下に入れている。

いずれも政府標準利用規約に沿い、各ページに出典を明記して利用している。
J-Net21 は利用条件でデータの取り込みが禁じられているため使っていない。
